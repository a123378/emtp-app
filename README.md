# EMT-P 高級救護技術員 — 醫學重點整理與題庫練習系統 🚑

專為高級救護技術員 (EMT-P) 打造的現代化線上臨床學習與模擬測驗系統。支援桌機與手機響應式介面，具備深淺色模式切換與直觀的研讀進度追蹤。

---

## 🌟 兩大核心模式

### 📋 模式一：重點整理 (CH01 ～ CH60)
- **60 章完整結構化講義**：涵蓋緊急醫療救護體系、困難呼吸道、心血管/12導程心電圖判定、重大創傷休克、神經急症、兒科產科、環境毒物急症等。
- **直觀研讀狀態標記**：
  - 🔴 紅色圓點：待研讀
  - 🟢 綠色圓點：已研讀（閱讀或手動點擊圓點切換）
- **章節歷屆考題隨堂測驗**：各章節開頭直接整合對應的歷屆甄試與小考試題，選取後立即公布詳細解析。
- **手機端專屬體驗**：抽屜式章節導航、滑動表格、夜間深色防疲勞配色。

---

### 📝 模式二：題庫練習 (四大核心功能)

1. **🤖 AI 智慧出題**
   - 串接 **Google Gemini API**（預設優先調用 `gemini-3.8-flash`）。
   - 可自訂專項出題領域（全科、心臟、創傷、呼吸道等）與難易度（甄試全真級 / 地獄挑戰級）。
   - 一鍵生成 10 題高擬真情境單選題與臨床詳解。

2. **🎲 歷屆全真抽測**
   - 整合 **108～113 年衛福部甄試題庫 + 新北市 EMTP 訓練階段小考 (Quiz 1～5)**。
   - 總題庫達 **355 題**，模擬考場無即時劇透，交卷後結算成績與詳細考點。
   - 附帶 **「🔗 跳轉至重點筆記」** 按鈕，點擊可直接切換回模式一對應章節複習。

3. **📚 章節專項出題**
   - 彈性勾選 CH01～CH60 或使用快捷範疇（創傷、心血管、呼吸道），針對薄弱環節集中訓練。

4. **📕 錯題本 & AI 弱點診斷**
   - 自動歸檔各項測驗之錯題，支援手動新增臨床題目。
   - **AI 弱點深度剖析**：Gemini 審閱錯題紀錄，診斷生理病理機轉與思維盲點，提供複習處方。
   - 支援隨機 10 題錯題針對性重測。

## 🛠️ 技術架構
- **純前端無後端依賴**：標準 HTML5、CSS3 (CSS Variables)、原生 JavaScript (ES6+)。
- **完全靜態部署**：可直接透過 GitHub Pages 進行雲端託管，免架設伺服器即可全球存取。
- **隱私安全**：Google Gemini API Key 僅儲存於使用者瀏覽器本機的 `localStorage`，不經過第三方伺服器。
