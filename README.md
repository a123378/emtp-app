# EMT-P 高級救護技術員 — 醫學重點整理系統 🚑

專為高級救護技術員 (EMT-P) 打造的現代化線上臨床學習系統。支援桌機與手機響應式介面，具備深淺色模式切換與直觀的研讀進度追蹤。

---

## 🌟 兩大核心模式

### 📋 模式一：重點整理 (CH01 ～ CH60)
- **60 章完整結構化講義**：涵蓋緊急醫療救護體系、困難呼吸道、心血管/12導程心電圖判定、重大創傷休克、神經急症、兒科產科、環境毒物急症等。
- **直觀研讀狀態標記**：
  - 🔴 紅色圓點：待研讀
  - 🟢 綠色圓點：已研讀（閱讀或手動點擊圓點切換）
- **章節歷屆考題隨堂測驗**：各章節開頭直接整合對應的歷屆甄試與小考試題，選取後立即公布詳細解析。
- **手機端專屬體驗**：抽屜式章節導航、滑動表格、夜間深色防疲勞配色。

## 📴 離線版

側欄按「📥 下載離線版」，會把全部章節、題庫、口試重點、心智圖與題目圖片（約 21 MB）存到這台裝置，之後沒有網路也能打開網頁讀筆記、做章內考題。跨裝置同步仍需網路。

- **不會卡舊版**：網頁與章節資料一律「網路優先」，有網路就拿最新版，斷網或網路超過 4 秒沒回應才用手機裡的版本。
- **自動增量更新**：下載過離線版的裝置，每次連網開啟時會在背景比對 `offline-files.json` 的檔案雜湊，只補抓有變動的檔案。
- **手動檢查更新**：側欄按「✅ 已可離線使用」再按「確定」，會立即檢查並下載有變動的檔案。
- **iPhone 注意**：請先「加入主畫面」再下載。只在 Safari 分頁使用時，iOS 可能在 7 天沒開啟後清掉離線資料。

相關檔案：`sw.js`（Service Worker 快取策略）、`offline.js`（側欄按鈕與進度）、`offline-files.json`（檔案清單，由 `scripts/build-offline-list.js` 產生）。

### 💻 電腦本機版（不需網路、不需部署）

在專案資料夾雙擊 **`開啟離線版.bat`**，會在背景啟動本機伺服器（`scripts/serve_local.py`，只開放 127.0.0.1:8770），並用預設瀏覽器打開網頁。內容直接讀這個資料夾裡的檔案，所以永遠是資料夾裡的最新版。

- 需要已安裝 Python（安裝時勾選 Add python.exe to PATH）。
- 伺服器以 `pythonw` 執行，**不會出現視窗**。
- **關掉瀏覽器（所有這個網頁的分頁）約 8 秒後伺服器自動停止**；只關其中一個分頁或重新整理不會停。瀏覽器當掉時最慢 3 分鐘停止；雙擊後 2 分鐘內都沒打開網頁也會停止。
- 再雙擊 .bat 會沿用已在執行的伺服器。
- 學習進度存在 `127.0.0.1:8770` 這個網址底下，和線上網站的進度分開；連網並登入跨裝置同步即可合併。
- 想要桌面圖示：用 Edge／Chrome 開啟後，從網址列的「安裝」按鈕安裝成 App（之後仍需先執行 .bat 啟動伺服器）。

**部署**：`deploy.bat` 會先執行 `node scripts/build-offline-list.js` 再上傳；若手動執行 `firebase deploy`，記得先跑這行，否則手機的離線包不會更新到新內容（線上瀏覽不受影響）。

## ☁️ 跨裝置同步（手機 ↔ 電腦）

已研讀章節與各章研讀進度預設存在瀏覽器的 localStorage，**綁單一裝置**。
接上免費的 Firebase 之後，用同一組帳號登入手機與電腦即可自動同步（另一台改動會即時拉下來）。

### 一次性設定（約 10 分鐘）

1. 到 [Firebase Console](https://console.firebase.google.com) → **建立專案**（Google Analytics 可略過）。
2. 左側 **Firestore Database** → 建立資料庫 → 選「**正式環境模式**」→ 位置建議 `asia-east1`。
3. 切到 **規則** 分頁，整段換成：

   ```
   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /emtp/{uid} {
         allow read, write: if request.auth != null && request.auth.uid == uid;
       }
     }
   }
   ```

   這條規則的意思是：**只有登入者本人讀得到、寫得進自己的資料**。

4. 左側 **Authentication** → 開始使用 → 登入方式選 **電子郵件/密碼** → 啟用。
5. **專案設定（齒輪）→ 一般 → 我的應用程式 → 網頁 `</>`** → 註冊應用程式 → 複製 `firebaseConfig` 那段。
6. 打開網頁右上角 **☁️** → 把 `firebaseConfig` 整段貼進去 → 儲存 → **註冊**一組帳號。
7. 手機打開同一個網址 → ☁️ → 貼同一段設定 → 用同一組帳密 **登入**。完成。

> 想省去在每台裝置貼設定的步驟，也可以把設定直接寫進 `sync.js` 最上面的 `FIREBASE_CONFIG` 並提交。
> Firebase 的網頁設定值本來就是公開資訊，安全性由上面的 Firestore 規則與登入帳號把關。

### 同步行為

| 資料 | 合併方式 |
| --- | --- |
| 已研讀章節 | 取聯集；取消已讀同樣會同步 |
| 各章研讀進度 | 兩台取較高的百分比；全書重設以重設端為準 |

沒設定、沒登入或離線時，網頁行為與原本完全相同，資料照常存在本機。
