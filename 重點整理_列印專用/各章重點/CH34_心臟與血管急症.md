# CH34 心臟與血管急症

## 🎯 學習目標

- 瞭解常見心臟血管系統急症之臨床表現。
- 瞭解常見心臟血管系統急症之緊急處置。

## 🔑 關鍵詞句及定義

| 中文術語 | 英文術語 (English) | 定義與核心精神 |
| :--- | :--- | :--- |
| **急性冠心症** | acute coronary syndrome | 又稱急性冠狀動脈症候群包括：不穩定性心絞痛、非ST段上升心肌梗塞，以及ST段上升心肌梗塞。 |
| **主動脈剝離** | aortic dissection | 主動脈血管壁的中層因各種原因(如高血壓或結締組織缺陷)受損後，血管壁內膜破裂造成身體各處的血液供應不足，形成肢體或腦部等處的缺血現象。 |
| **肺動脈栓塞** | pulmonary embolism | 肺動脈或其分支發生血栓阻塞。 |
| **心包膜填塞** | cardiac tamponade | 心包腔內積液增加，導致心包腔壓力上升，造成靜脈回流受阻，心搏出量減少，而產生低血壓或休克等情形。 |
| **心臟衰竭** | heart failure | 指心臟功能衰退，以致無法提供有效循環及組織新陳代謝需求。 |
| **心因性休克** | cardiogenic shock | 因為心臟衰竭所造成的低心輸出量，而引起組織灌流不足的臨床徵候。 |
| **心律不整** | arrhythmia | 泛指心臟發生不正常的心律，可能是頻脈、緩脈，或是不規則心律。 |

## 📖 內文重點整理

### 📙 急性胸痛概論

當病人發生急性胸痛時，有幾個可能危及生命的急症，必須要列入鑑別診斷：

- 急性冠狀動脈症候群，或急性冠心症
- 主動脈剝離
- 肺動脈栓塞
- 張力性氣胸
- 心包膜填塞
- 食道破裂

### 📙 急性冠心症

包括：不穩定性心絞痛、非ST段上升心肌梗塞，以及ST段上升心肌梗塞。急性冠心症是心因性猝死最常見的原因。治療目標在於：盡量減少急性心肌梗塞心肌壞死的範圍、預防重大併發症、治療急性併發症。

#### 📘 診斷

急性心肌梗塞的診斷標準（三項中至少兩項成立）：
1. 具有診斷性的症狀，如典型胸痛
2. 具有診斷性的心電圖變化
3. 心肌酵素的升高

三大非典型族群（常無典型症狀）：糖尿病病人、老年人、婦女。

- 與呼吸相關的胸痛：通常與肋膜等疾病有關
- 與姿勢相關的胸痛：如仰臥時胸痛，坐起前傾可緩解，應考慮心包膜炎
- 有壓痛點的胸痛：通常為骨骼肌肉或筋膜問題所致

ST段上升心肌梗塞演進變化：
1. 超急性T波(hyperacute T)：心肌梗塞後第一個小時出現。
2. ST節段上升(ST segment elevation)：以J點+0.04秒為基準點。
3. Q波的產生：1小時內至1天以後發生，不具動態性。
4. ST節段逐漸回復至基準線。
5. T波倒立：發生於1~3週，有重灌流現象產生。

- 體表心電圖與解剖位置：
  - 導程Ⅱ、Ⅲ、aVF：下壁心肌梗塞；右冠狀動脈阻塞
  - 導程V1、V2：心室中隔心肌梗塞；左前降枝冠狀動脈阻塞
  - 導程V3、V4：前壁心肌梗塞；左前降枝冠狀動脈阻塞
  - 導程V5、V6：側壁心肌梗塞；左回旋枝冠狀動脈阻塞
  - 導程Ⅰ、aVL：高位側壁心肌梗塞；右冠狀動脈或左回旋枝阻塞
  - 導程V4R：右心室心肌梗塞；右冠狀動脈阻塞
  - 導程V1至V4 ST下降：後壁心肌梗塞倒影現象(reciprocal changes)；右冠狀動脈阻塞

#### 📘 臨床處置

- 將病人放置於舒適的姿勢休息
- 測量氧氣飽和度，血氧小於90%才考慮使用氧氣，維持在94~98%
- 迅速運送就醫
- 若無禁忌症，給予aspirin 160~325毫克
- 建立靜脈管路
- 連接十二導程心電圖，若為STEMI立即通知責任醫院啟動心導管小組
- 依授權給予nitroglycerin及morphine減輕疼痛，或處理心律不整藥物

### 📙 主動脈剝離

主動脈血管壁中層受損，內膜破裂，血液進入血管壁形成「假腔」。典型症狀為劇烈撕裂性胸痛，常轉移至背部。史丹福(Stanford)分類以有無侵犯升主動脈區分：侵犯升主動脈為A型（建議手術），其餘為B型（藥物控制血壓為主）。

| 診斷工具 | 敏感度 | 特定度 |
| :--- | :--- | :--- |
| Aortography (血管攝影) | ++ | +++ |
| CT (電腦斷層) | ++ | +++ |
| MRI (核磁共振) | +++ | +++ |
| TEE (經食道心臟超音波) | +++ | ++/+++ |

#### 📘 臨床處置

- 若為典型主動脈剝離症狀，避免給予Asipirin。
- 將病人放置於舒適姿勢休息，測量血氧，維持94~98%。
- 建立靜脈管路，迅速就醫。
- 若肢端無脈象或左右肢血壓差大於20 mmHg以上，應高度懷疑主動脈剝離。
- 內科治療目標：收縮壓控制在100~120 mmHg，心跳60~80次/分。

### 📙 腹主動脈瘤

常以腹痛、腹脹及下背痛表現。破裂進入腹腔時造成低血容性休克，死亡率極高。若高度懷疑，應積極輸液並後送能緊急處理的醫院。

### 📙 肺動脈栓塞

肺動脈或其分支發生血栓阻塞，常由下肢深部靜脈血栓引起。症狀包括呼吸急促、胸痛（肋膜性）、咳嗽等。心電圖可能出現「S1Q3T3」或右心室過度負荷現象。

#### 📘 臨床處置

- 維持血氧飽和度在94~98%。
- 若嚴重影響血流動力學，可給予輸液或升壓劑，維持收縮壓90mmHg以上。
- 急診常使用抗凝血劑(肝素、warfarin或NOAC)或血栓溶解劑。

### 📙 心包膜填塞

心包腔內積液，導致心包腔壓力上升，靜脈回流受阻。

- 貝克氏三症狀 (Beck's triad)：
  - 低血壓
  - 頸靜脈怒張
  - 心音變弱且模糊
- 其他徵象：奇脈(pulsus paradoxus)、心電圖電氣交替(electrical alternans)。

#### 📘 臨床處置

- 高度懷疑者，到院前建立靜脈管路並給予生理食鹽水，迅速就醫。
- 不適合使用胸痛流程中的MONA治療。
- 確定治療：心包膜穿刺術、心包膜切開術。

### 📙 心臟衰竭及心因性休克

左心室衰竭常導致肺水腫。表現包括呼吸困難(端坐呼吸)、發紺、盜汗、肺部聽診有囉音、頸靜脈怒張等。

#### 📘 臨床處置

- 保持半坐臥姿勢，給予高流量氧氣，維持血氧94~98%以上。
- 急性肺水腫無合併低血壓及休克 (收縮壓>100mmHg)：
  - 第一線治療(LMNO)：furosemide (Lasix) 0.5~1.0mg/kg、morphine 2~4mg、nitroglycerin舌下片、氧氣。
- 急性肺水腫合併低血壓，但無休克 (收縮壓70~100mmHg)：
  - 選用dobutamine靜脈滴注 2~20μg/kg/min。不宜使用Lasix、morphine、NTG。
- 急性肺水腫合併低血壓及休克 (收縮壓<70mmHg)：
  - 首選dopamine，若無效則考慮norepinephrine 0.5~30μg/kg/min。

### 📙 心律不整

#### 📘 頻脈性心律不整

- 窄QRS波頻脈 (<0.12秒)：
  - 竇性頻脈 (ST)
  - 心房顫動 (Af)
  - 心房撲動 (AF)
  - 上心室頻脈 (SVT)
- 寬QRS波頻脈 (≥0.12秒)：
  - 心室頻脈 (VT)

#### 📘 頻脈之臨床處置

若有血流動力學不穩定徵候(低血壓、休克、缺血性胸痛、急性心衰竭、意識改變)，應立刻進行同步心臟整律(synchronized cardioversion)。
穩定的窄QRS波(如SVT)：首選 adenosine 6mg 快速靜注，無效則12mg。
穩定的寬QRS波(如VT)：首選 amiodarone 150mg 緩慢靜注10分鐘。

#### 📘 緩脈性心律不整

心跳<60下且伴隨灌流不良症狀(低血壓、意識改變、胸痛等)。
第一線治療：Atropine 1mg靜推(最大3mg)；經皮心臟節律器(TCP)；Dopamine 5~20μg/kg/min滴注；Epinephrine 2~10μg/min滴注。

### 📙 昏厥

#### 📘 原因

- 心因性：心肺結構問題或心律不整(如VT)。
- 神經反射相關：迷走神經性昏厥(Vasovagal)最常見(約兩成)。

#### 📘 臨床處置

詢問發作情境，評估是否有發作後期混亂(Postictal Confusion)以排除癲癇。進行完整十二導程心電圖檢查及理學檢查以排除危險診斷。

### ⚡ 快速複習核心要點

- 急性胸痛應優先排除：急性冠心症、主動脈剝離、肺栓塞、張力性氣胸、心包膜填塞、食道破裂。
- 急性心肌梗塞典型症狀包括壓迫性胸痛、移轉痛及冒冷汗，但老人、女性及糖尿病患常以非典型症狀表現。
- ST段上升心肌梗塞需盡早進行再灌流治療，若無禁忌症可給予Aspirin、NTG及氧氣。
- 主動脈剝離典型症狀為撕裂性胸痛，兩手血壓差大於20mmHg，Stanford A型需緊急手術。
- 肺栓塞常源於下肢深部靜脈血栓，表現為呼吸急促、胸痛及右心負荷增加。
- 心包膜填塞的Beck's triad為：低血壓、頸靜脈怒張、心音微弱。
- 急性肺水腫伴血壓正常或升高時，可使用LMNO (Lasix, Morphine, NTG, Oxygen)。
- 頻脈若有血流動力學不穩定，應立刻進行同步心臟整律。
- 穩定之規則窄QRS波頻脈首選藥物為 Adenosine。
- 有症狀之緩脈第一線用藥為 Atropine，無效則考慮 TCP 或 Dopamine/Epinephrine 滴注。
