# CH16 緊急救護藥理學

## 🎯 學習目標

- 瞭解何謂藥理學及藥物是什麼。
- 瞭解同一藥物的四種不同名稱及其所代表的意義。
- 學習區別出藥物的不同劑型。
- 瞭解藥物如何在體內達到治療效果。
- 瞭解哪些因素會影響藥物的吸收、分佈、生物轉化與排除。
- 瞭解藥物如何藉由接受體達到藥效並知道有哪些常用的給藥途徑。
- 學習各種作用在不同系統之藥物及各類急救藥物的作用、臨床適應症及相關注意事項。

## 📖 內文重點整理

### 📙 基本藥理學

凡能改變或影響生理功能之化學物質都可以稱之為藥物。藥理學探討藥物來源、組成結構、物理與化學特性、作用機轉、吸收、分佈、代謝、排泄、治療用途、用法、藥效、不良反應與藥物相互作用等。

#### 📘 藥物資訊

- 化學名(chemical name)：根據藥物的化學結構式來命名。例如 para-acetylaminophenol。
- 俗名(generic name)：正式名稱。教科書採用，通常字首小寫即可。例如 Acetaminophen、Diazepam。
- 商品名(trade name)：藥廠命名的商標名，字首大寫並有®標記。例如 Tylenol®、Panadol®。
- 學名(official name)：登錄在美國藥典(USP)或國家處方集(NF)的名稱。

| 商品名 | 俗名 |
| :--- | :--- |
| Adrenaline®、Bosmin® | Epinephrine |
| Bokey®、Tapal®、Aspirin® | Acetylsalicylic acid(乙醯水楊酸) |
| Atropine®、阿托品 | Atropine sulfate |
| Adenosine® | Adenosine-phosphate |
| Nitrostat® | Nitroglycerin(NTG) |
| Cordarone® | Amiodarone |
| Jusomin®、Rolikan®、Soda® | Sodium Bicarbonate |
| Vitacal® | Calcium chloride |

#### 📘 管制藥品

依管制藥品管理條例分為四級，嗎啡為第一級，Diazepam、Midazolam和Lorazepam為第四級，Ketamine為第三級，Tramadol為第四級。救護技術員得依預立醫囑給予特定管制藥物。

### 📙 藥物如何發生作用

#### 📘 藥物的特性

藥物會產生治療作用及副作用。作用階段包含：
1. 藥劑學階段：藥物配製與溶解。
2. 藥物動力學階段：吸收、分佈、生物轉化、排泄。
3. 藥物效力學階段：藥物與受體之相互作用。

> ### 📦 Box16-1 藥理學基本名詞
> <p>包含拮抗作用、禁忌症、累積效應、藥物相互作用、加成作用、協同作用、適應性(耐受性)等。</p>

#### 📘 藥物吸收

- 吸收表面性質：小腸大於胃部。
- 血流量：肌肉注射大於皮下注射。
- 可溶性：脂溶性大於水溶性。
- 酸鹼值：非離子態易吸收，弱酸在酸性環境中吸收佳。
- 濃度：給予負荷劑量(loading dose)可快速達到治療濃度，後以維持劑量保持。
- 劑型：如腸衣錠可抗消化。

| 投予方式 | 縮寫 | 速率 |
| :--- | :--- | :--- |
| 口服(Orally) | P.O. | 慢 |
| 舌下(Sublingual) | S.L. | 快 |
| 直腸給藥(Rectal) | PR/SUPP | 慢或中等 |
| 皮下注(Subcutaneous) | S.C. | 慢 |
| 肌肉注(Intramuscular) | I.M. | 中等 |
| 靜脈注射(Intravenous) | I.V. | 立即 |
| 骨內注射(Intraosseous) | I.O. | 立即 |
| 霧氣吸入(Inhalation) | I.H. | 立即 |
| 氣管內管(Endotracheal) | E.T. | 快 |

#### 📘 生物轉化與排泄

- 首渡效應：口服藥在進入全身循環前，先經肝臟代謝而失去部分活性。
- P-450酵素：影響代謝速率。
- 腎臟排泄：包括腎絲球被動過濾、腎小管主動排泄及部份再吸收。

| 分級 | 懷孕風險 | 藥物舉例 |
| :--- | :--- | :--- |
| A級 | 無風險 | 葉酸 |
| B級 | 動物實驗無風險 | 胰島素、普拿疼 |
| C級 | 動物實驗有負面影響 | Albuterol |
| D級 | 有人類負面影響證據但利大於弊 | 鋰鹽、Captopril |
| X級 | 絕對禁用 | A酸、沙利竇邁 |

> ### 💡 核心觀念 ‧ 臨床實務
> - 某些藥物在急救時給予的劑量比平常大，是為了達到負荷劑量快速起效。

### 📙 影響神經系統的急救藥物

- 腎上腺素 (Epinephrine)
  - 受體：非選擇性 α1、β1、β2
  - 作用：活化心臟增加收縮與心跳(β1)，擴張支氣管(β2)，收縮周邊血管升壓(α1)
  - 適應症：心跳停止、有症狀心搏過慢、過敏性休克
- 阿托平 (Atropine)
  - 受體：抗蕈毒鹼(副交感抑制)
  - 作用：加速心竇/心房節律，增加房室傳導
  - 適應症：有症狀緩脈、有機磷中毒
  - 注意事項：低劑量(<0.1mg)可能致心率更慢
- Midazolam (Dormicum®)
  - 類別：BZD類，第四級管制
  - 劑量：IV 0.3mg/kg
  - 作用：鎮靜、抗癲癇
  - 注意：可能引起呼吸抑制、低血壓
- Ketamine (Ketalar®)
  - 類別：第三級管制
  - 劑量：IV 1~2mg/kg
  - 作用：止痛、鎮靜、升血壓
  - 注意：可能出現喉頭痙攣、眼壓升高

### 📙 影響心血管系統的急救藥物

- Amiodarone (Cordarone®)
  - 類別：Class III 抗心律不整
  - 適應症：電擊無效之pVT/VF、多型性心室頻脈、AF
  - 注意：可能引致血管擴張降血壓、延長QT
- Adenosine (Adenocor®)
  - 適應症：治療PSVT
  - 注意：必須快速注射，會出現短暫胸悶、心跳停止感
- Aspirin
  - 適應症：ACS病人第一線
  - 注意：抑制血小板不可逆，急性潰瘍/過敏禁用
- NTG
  - 適應症：心絞痛、急性肺水腫
  - 注意：收縮壓勿低於90mmHg，24小時內禁用威而鋼類

## ⚡ 重點一覽（公式、數值與衝刺要點）

### 🧮 公式彙整

- **治療指標 (TI)**：`TI = LD50 ÷ ED50`
  - *說明*：TI越大藥物越安全

### 🔢 重要數字 / 數值對照表

| 項目 | 關鍵數值 | 臨床說明 |
| :--- | :--- | :--- |
| **Atropine** | `<0.1mg` | 過低劑量會反向造成心跳減慢 |
| **Amiodarone半衰期** | `40天` | 藥效非常長 |
| **Digoxin治療濃度** | `0.8~2.0 ng/mL` | 治療指數窄，易中毒 |
| **Epinephrine氣管內給藥劑量** | `2~2.5倍` | 需用生理食鹽水稀釋至10ml |

### ⚡ 快速複習核心要點

- 藥物吸收受血流、溶解度、酸鹼值影響，脂溶性及非離子態易通過細胞膜。
- 首渡效應發生在肝臟，大幅降低口服藥進入系統循環的有效濃度。
- 靜脈注射吸收最快，其次為骨內與氣管內給藥。
- α1受體活化造成血管收縮、血壓上升。
- β1受體活化造成心跳加快、收縮力增強。
- β2受體活化造成支氣管與血管平滑肌擴張。
- Amiodarone與Procainamide等抗心律不整藥物不可隨意混用，易延長QT。
- NTG使用前需確認收縮壓>90mmHg且近期未使用PDE5抑制劑。
- Midazolam、Ketamine可用於DAI(藥物輔助插管)之鎮靜與誘導。
- 鈣離子與碳酸氫鈉(Bicarbonate)絕對不可在同一管路混合以免產生沉澱。
