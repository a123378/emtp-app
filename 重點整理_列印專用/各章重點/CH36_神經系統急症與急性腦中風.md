# CH36 神經系統急症與急性腦中風

## 🎯 學習目標

- 能夠瞭解人體神經系統的基本構造及其運作的方式。
- 能夠熟悉常見的神經學症狀及其代表的意義。
- 能夠熟悉常用的神經學檢查及其代表的意義。
- 能夠了解常見神經系統急症的臨床表現、致病原因、治療方式、預後、及可能的併發症。
- 能夠實際運用於到院前病人的照護和處置。

## 📖 內文重點整理

### 📙 神經系統構造概論

神經細胞(神經元)是組成神經系統的基本構造。其組成包含了細胞本體以及兩種特化的突起構造，分別稱作樹突和軸突。樹突將訊息帶入細胞本體，而軸突則是將訊息自細胞本體傳出。

突觸是兩個神經元之間的微小空隙，一個神經元可以經由突觸將訊息傳送到另一個神經元。突觸前的神經末梢內含有神經傳導物質，突觸後的神經則含有神經傳導物質的接受體。

- 神經系統的主要神經傳導物質有乙醯膽鹼(acetylcholine)、多巴胺(dopamine)、正腎上腺素(norepinephrine)和腎上腺素(epinephrine)等。
- 神經系統分為中樞神經系統和周邊神經系統。中樞神經系統包括了「腦」和「脊髓」。周邊神經系統分成「軀體神經系統」和「自律神經系統」。

#### 📘 腦脊髓液 (Cerebrospinal Fluid, CSF)

整個中樞神經系統都沈浸在一層澄淨透明的腦脊髓液中。

- 總體積：約為125~150毫升。
- 壓力：介於10~15 mmHg。
- 產生與循環：主要由側腦室，第三、第四腦室的脈絡叢(choroid plexus)產生。由側腦室流向第三腦室，再經由大腦導水管(cerebral aqueduct)通向第四腦室，最後流入蜘蛛網膜下腔。藉由蜘蛛膜絨毛(arachnoid villi)吸收進入血管。
- 水腦：當管道阻塞或腦脊髓液產量過多會造成水腦。

- 腦脊髓液的功能
  - 保護：有緩衝功效，保護腦部減少損傷。
  - 浮力：減輕腦部底層的壓力。
  - 新陳代謝：以單向流通方式，將代謝物質、藥物帶至血液。
  - 腦內激素的運送。

#### 📘 腦部的血液供給

人腦占身體總重量的2%，卻擁有身體15~20%的血液供給。血氧中斷將導致腦細胞死亡，因此腦部在人體血液供給享有第一優先順序。

- 內頸動脈(internal carotid arteries)：左右各一，分為前、中、後大腦動脈，主要供應前腦血流。
- 椎動脈(vertebral arteries)：右側與左側椎動脈在腦底部形成基底動脈(basilar artery)，主要負責小腦和腦幹的血流供應。
- 威利氏環(circle of Willis)：基底動脈與內頸動脈在腦底部合成的環狀血管。當動脈阻塞時，腦細胞可藉由威利氏環得到其他血管血液的支援。

### 📙 神經病理學

腦部組織結構改變、破壞或血流供應問題是造成神經系統急症的結果。其中腦部灌流壓力(Cerebral Perfusion Pressure, CPP)不足是主要原因。

- 腦部灌流壓力決定腦部血流量。CPP = MAP(平均動脈壓) - ICP(顱內壓力)。
- 顱內壓力(ICP)主要來源：腦組織體積、腦血流量及腦脊髓液。
- 自動調節機制：顱內壓上升時，人體使平均動脈壓上升，以維持CPP在80mmHg左右。
- 當顱內壓力大於22mmHg時，自動調節機制會失去作用。這時必須立即給予降腦壓治療，防止腦部缺血造成不可逆損害。

### 📙 病人評估原則及常用的神經學檢查

#### 📘 到院前救護目標

- 維持呼吸道的通暢及有效的換氣。
- 維持足夠且穩定的循環功能。
- 盡可能排除會進一步造成神經系統惡化的原因。
- 盡速將病人安全送到合適的治療機構。

#### 📘 初步評估

快速對病人的意識、呼吸道、呼吸和循環進行評估並給予適當處置。提供足夠氧氣和有效換氣是必須的。

- 血氧分壓(PO2)過低或二氧化碳分壓(PCO2)過高會造成腦血管擴張、腦血流量增加，使顱內壓上升。
- 過度換氣治療：當PCO2控制在30mmHg左右時，可減少腦部血流量，但過低可能導致腦血管過度收縮加重缺血。
- 使用過度換氣條件：出現庫欣氏三徵象(血壓升高及脈搏壓加寬、心跳變慢、呼吸變慢或不規則)及單側瞳孔變大對光無反應，且有PCO2監測器監控下才建議小心使用。

#### 📘 二度評估

找出造成病人發生神經系統急症的可能原因，取得詳細主訴、現病史、過去病史及用藥史，並注意現場環境。

#### 📘 意識檢查

- 常見評估方法：AVPU及GCS。
- 不正常的姿勢：
  - 去皮質僵直(decorticate rigidity)：單/雙側上肢彎曲及下肢伸張，代表大腦半球皮質受損。
  - 去大腦僵直(decerebrate rigidity)：單/雙側上、下肢皆伸張，代表中腦、腦幹受損，預後非常差。

#### 📘 腦幹功能的評估

- 瞳孔的對光反射：
  - 縮小反應與視神經(II)傳入及動眼神經(III)副交感神經傳出有關。
  - 單側照光，雙側同時出現縮瞳且瞳孔等大。若被照光側未縮小，表示第三對腦神經受損或中腦、腦幹有病兆。
  - 意識不清且出現單側固定放大瞳孔對光無反應，表示神經損傷極嚴重。
- 洋娃娃眼徵象(doll's eye sign)：
  - 固定上眼瞼快速轉動頭部。正常腦幹功能眼球會往頭轉動方向的對側移動(陽性)。
  - 腦幹功能失常則眼球持續固定在正中央。
- 巴賓斯基反射(Babinski sign)：
  - 陽性代表中樞神經系統運動傳導路徑有問題。單側陽性代表對側腦部受損。

> ### 💡 核心觀念 ‧ 臨床實務
> - 67歲女性，GCS評分為 E1V1M3 (對痛無睜眼，無聲音，去皮質僵直)。
> - 庫欣氏三徵象出現：脈搏慢(52)、呼吸不規則(18)，暗示顱內壓升高(IICP)。
> - 立即處置包括：維持呼吸道暢通，給予適當氧氣，避免進一步缺氧，盡速送醫。

### 📙 常見神經系統急症的介紹及治療處置

#### 📘 昏迷

昏迷(coma)指無法對外界刺激做出適當反應。維持清醒依賴腦幹網狀活化系統(reticular activating system)及大腦半球。

| 臨床表現 | 毒性物質或代謝物質 | 結構上的病灶 |
| :--- | :--- | :--- |
| 異常的呼吸型態 | 無 | 有 |
| 神經學異常 | 大多是對稱性的 | 常常是不對稱的 |
| 瞳孔反射 | 大多是正常 | 異常或不對稱 |

> ### 📦 Box36-1 昏迷的原因(AEIOU-TIPS)
> <p>A: Alcohol, acidosis<br>E: Encephalopathy, Endocrinopathy, Electrolytes<br>I: Insulin (低血糖, DKA與HHNK)<br>O: Opiates, Oxygen, overdose<br>U: Uremia<br>T: Trauma<br>I: Infection<br>P: Psychogenic causes<br>S: Seizure, Syncope, Space occupied lesion</p>

- 到院前的評估和處置：
  - 依意識ABC原則處理，保護呼吸道(視情況給予口/鼻咽呼吸道或氣管內管)，給予氧氣/正壓給氧。
  - 建立靜脈管道，驗指尖血糖值。低血糖給予50%葡萄糖水或含糖輸液。
  - 側躺姿勢方便引流分泌物，準備抽吸器材。
  - 懷疑酒精中毒：給葡萄糖水前先給Thiamine(維他命B1)預防嚴重神經損傷。
  - 懷疑鴉片類成癮：給予解毒劑Naloxone，需注意戒斷躁動並準備保護約束。

#### 📘 急性腦中風 (acute stroke)

學名腦血管疾病，或腦血管意外(CVA)。死亡率極高，臨床症狀為突然且劇烈的局部性神經機能障礙。

- 出血性腦中風(約15%)：
  - 腦內出血(ICH)：高血壓合併動脈硬化致血管破裂。好發於冬天，常在忙碌、情緒亢奮或解便中發病。
  - 蜘蛛網膜下腔出血(SAH)：動脈瘤或先天性動靜脈血管異常破裂。多為年輕人或中老年男性。
- 缺血性腦中風(約85%)：
  - 動脈硬化狹窄產生血栓，或他處(如心臟)栓子堵塞腦血管。
  - 容易發生在睡眠中或剛睡醒時。
  - 80%缺血性腦中風前有暫時性腦缺血發作(TIA)。

- 常見腦中風症狀：
  - 半側肢體無力。
  - 感覺消失或感覺異常。
  - 失語症：表達型(無法表達)、理解型(答非所問)、全面型(完全喪失溝通能力)。
  - 視野缺損：半側視野缺損、複視、眼震等。
  - 顱神經障礙：顏面神經麻痺(嘴角歪)、三叉神經麻痺(半邊臉麻)、動眼神經麻痺、第八對腦神經障礙(頭暈、嘔吐、聽力障礙)。

- 不同阻塞部位症狀：
  - 左側中大腦動脈第一分支阻塞：右側無力、眼睛往左看、右側偏盲、右側感覺變差、失語症。
  - 右側中大腦動脈第一分支阻塞：左側無力、眼睛往右看、左側偏盲、左側感覺變差、忽略症(neglect)。
  - 前大腦動脈阻塞：對側下肢無力、反應變鈍、執行功能失常(executive dysfunction)。
  - 後大腦動脈阻塞：對側偏盲、若影響中腦可能有對側無力。
  - 基底動脈阻塞：影響腦幹功能、顱神經失調、雙側橋腦受損導致閉鎖症候群(locked)。

#### 📘 腦中風到院前的治療與處置

- 血栓溶解劑(t-PA)：符合條件且無禁忌症者，應在症狀發作4.5小時之內接受治療。
- 動脈血管內血栓移除治療(EVT)：發作6小時內之大血管阻塞。DEFUSE III試驗延長至16小時，DAWN試驗延長至24小時。

| 辛辛那提到院前腦中風評量表(CPSS) | 說明 |
| :--- | :--- |
| 手臂下垂 (arm drift) | 要求病人雙手平舉10秒鐘，評估是否有單側無力或手臂下垂 |
| 臉下垂 (facial droop) | 請病人露齒微笑，評估臉部嘴唇是否對稱 |
| 說話 (speech) | 請病人重複你說的話，評估是否有口齒不清答非所問或無法表達 |

> ### 📦 Box36-2 台北市到院前辨認出疑似大血管阻塞的病人之經驗
> <p>利用 G-FAST 指標分數 (Gaze–Face–Arm–Speech–Time score) 進行辨識，四項神經學檢查有三項以上異常即為陽性。若陽性且在黃金時間內，進行繞道送至可提供動脈內血栓移除治療的醫院。</p>

- 到院前處置原則：
  - 評估ABC，裝上心律監視器。
  - 維持血氧濃度 ≧ 94%。
  - 建立靜脈路徑，避免過多水分以免增加腦水腫。
  - 測量血糖，低血糖給葡萄糖水；無低血糖勿給含糖輸液。
  - 建議病人空腹防吸入性肺炎。
  - 避免積極使用血管擴張劑降血壓。
  - 提前告知接收醫院急診室啟動中風小組。
  - 平躺後送，懷疑IICP則頭部抬高但不超過30度。

> ### 💡 核心觀念 ‧ 臨床實務
> - 張太太右側肢體對痛無反應，可能是左側大腦中風。
> - 送醫前需進行CPSS或LAPSS評估，確認發作時間，監測血糖以排除低血糖。
> - 通報時告知：可能為急性腦中風、發作時間、生命徵象、相關病史(高血壓)，以便醫院啟動中風小組。

### 📙 抽搐或癲癇

腦部神經元細胞異常電氣活動導致身體不自主活動或意識改變。

- 全身性抽搐發作(generalized onset)：
  - 失神小發作(absence seizure)：短暫意識喪失，無劇烈肢體抽動。
  - 大發作(grand mal)：喪失意識及肌肉張力。僵直期(tonic)伴呼吸中止，陣攣期(clonic)抽搐與鬆弛交替。
  - 失張力發作(atonic seizure)：肌肉張力突然消失，小於2秒。
  - 肌抽躍發作(myoclonic seizure)：短暫肌肉收縮抖動。
- 癲癇重積狀態(status epilepticus)：持續大發作超過5分鐘，或兩次發作間未恢復意識。若不儘快治療可能呼吸衰竭。
- 局部發作(focal onset)：
  - 單純型：神智清楚，產生各種局部症狀(如額葉抽動、枕葉閃光)。
  - 複雜型：合併神智逐漸喪失，常有漫無目的動作(紮嘴、繞圈)。
  - 次發性大發作：局部放電擴大至整個大腦。

- 到院前的評估和處置：
  - 移至安全處，不強制約束，不強塞物品入嘴。
  - 停止抽搐後擺復甦姿勢引流分泌物，給予高濃度氧氣。
  - 重積狀態者：依醫囑給予抗癲癇藥物(Lorazepam, diazepam, midazolam)，建立靜脈管路。
  - 必須送醫情況：型態改變、合併外傷/發燒/懷孕、初次發作、癲癇重積狀態。

### 📙 頭痛

- 原發性頭痛：
  - 張力性頭痛：持續性鈍痛，與壓力/緊繃肌肉有關。
  - 偏頭痛：強烈抽痛，伴視力模糊/畏光/噁心，好發年輕女性，有時有先兆。
  - 叢聚性頭痛：好發男性菸癮者，突發持續數週，與組織胺釋放有關，伴結膜充血/流淚。
- 警訊(warning signs)：
  - 突發急性頭痛、型態改變、情況變糟。
  - 伴隨外傷、發燒或懷孕。
  - 意識不清或新神經學異常。
  - 年紀<5歲或>50歲初次發生。

| :--- | :--- | :--- |
| 病灶部位 | 內耳迷路 | 前庭神經中樞 |
| 耳朵症狀 | 聽力減弱、耳鳴 | 無 |
| 眼震 | 單一方向 | 多方向 |
| 其他神經症狀 | 無 | 有(言語不清、複視等) |

- 顏面神經麻痺：
  - 中樞性：對側下半部麻痺，仍可皺眉/閉眼。代表嚴重腦疾病。
  - 周邊性：同側整個臉麻痺，無法皺眉/閉眼。如貝爾氏麻痺(Bell's palsy)。

> ### 📦 Box36-5 貝爾氏麻痺
> <p>最常見的一種顏面神經麻痺，原因不明或病毒感染。預後良好，80%在2~6週自行恢復。急性期前7天可使用類固醇，對閉眼困難者予以眼罩保護。</p>

### 📙 重症肌無力 (Myasthenia gravis)

自體免疫疾病，抗體攻擊肌肉接收器導致肌肉無力。典型特徵是休息後力量恢復，活動後加重。

- 最嚴重併發症為肌無力危象(Myasthenia crisis)，影響呼吸肌肉導致呼吸衰竭。
- 到院前處置需特別注意肌無力危象，給予高濃度氧氣，必要時甦醒球正壓給氧。

### 📙 運動神經元疾病 (漸凍人)

主要病變為上下運動神經元受損。最常見為脊髓側索硬化(ALS)。

- 上神經元受損：四肢緊繃、協調困難、肌肉僵硬、反射增強。
- 下神經元受損：肌肉萎縮向上蔓延，最終影響呼吸肌肉。感覺神經未受損，意識清楚。
- 救護重點著重呼吸道與呼吸評估，必要時抽吸、給氧、正壓通氣。

> ### 💡 核心觀念 ‧ 臨床實務
> - 70歲男性，發燒、意識不清後突發全身抽搐並缺氧。
> - 通報內容需包含：懷疑感染導致癲癇發作或癲癇重積狀態，血氧下降情形。
> - 處置：保護頭部，抽搐停止後給予氧氣或正壓換氣。線上指導可詢問給予抗癲癇藥物(如diazepam)及建立靜脈管路。

## ⚡ 重點一覽（公式、數值與衝刺要點）

### 🧮 公式彙整

- **腦部灌流壓力(CPP)**：`CPP = MAP - ICP`
  - *說明*：腦部灌流壓力等於平均動脈壓減去顱內壓力

### 🔢 重要數字 / 數值對照表

| 項目 | 關鍵數值 | 臨床說明 |
| :--- | :--- | :--- |
| **腦部重量** | `2%` | 占身體總重量，但享有15~20%血液供給 |
| **腦脊髓液總體積** | `125~150 毫升` | 正常腦脊髓液總體積 |
| **腦脊髓液壓力** | `10~15 mmHg` | 正常腦脊髓液壓力 |
| **正常CPP目標** | `80 mmHg` | 正常腦部灌流壓力目標值 |
| **顱內壓失調臨界點** | `22 mmHg` | 顱內壓大於此數值時，自動調節機制會失去作用 |
| **PCO2控制目標(過度換氣)** | `30 mmHg` | 控制在此數值可減少腦部血流量 |
| **靜脈血栓溶解劑(t-PA)黃金時間** | `4.5 小時` | 急性缺血性腦中風發生後，符合條件內使用 |
| **動脈內血栓移除治療(EVT)時間** | `6~24 小時` | 依不同試驗條件(DEFUSE III, DAWN)，可達24小時 |
| **目標血氧濃度** | `≧ 94%` | 腦中風病人到院前處置建議維持之血氧濃度 |
| **腦中風病人頭部抬高極限** | `30 度` | 懷疑IICP時頭部抬高角度 |

### ⚡ 快速複習核心要點

- 腦神經元依賴乙醯膽鹼、多巴胺等神經傳導物質傳遞訊息。
- 庫欣氏三徵象(Cushing's triad)包含：血壓升高及脈搏壓加寬、心跳變慢、呼吸變慢或不規則，代表顱內壓上升。
- 去大腦僵直(四肢伸張)代表中腦、腦幹受損，預後極差。
- 巴賓斯基反射陽性代表中樞神經系統運動傳導路徑受損。
- AEIOU-TIPS是幫助記憶造成昏迷常見原因的口訣。
- 缺血性腦中風占85%，部分發作前有暫時性腦缺血發作(TIA)先兆。
- 辛辛那提到院前腦中風評量表(CPSS)評估：手臂下垂、臉下垂、說話異常。
- 中風病人避免積極給予降血壓藥物及含糖輸液(除非低血糖)。
- 抽搐病患若發作超過5分鐘或連續發作未清醒，即為癲癇重積狀態，需積極處置避免呼吸衰竭。
- 中樞性顏面神經麻痺僅對側下半部臉麻痺，周邊性(如貝爾氏)則是同側全臉麻痺。
- 重症肌無力最嚴重併發症為影響呼吸肌的肌無力危象。
- 運動神經元疾病(ALS)末期病人運動神經萎縮無法呼吸，但感覺與意識均完全正常。
