## 🔑 關鍵詞句及定義

| 中文術語 | 英文術語 (English) | 定義與核心精神 |
| :--- | :--- | :--- |
| **解剖死腔或稱解剖性無效腔** | anatomical dead space | 自鼻腔以下至終端細支氣管間所有呼吸道管腔空間的組合，在此空間內的氣體因為沒有進入肺泡，不能行氣體交換，故稱之為無效腔。 |
| **肺塌陷** | atelectasis | 正常的肺泡內應充滿氣體而膨脹，即使用力呼氣也不會全部排出，若是因為病變導致肺泡組織塌陷，氣體將無法進出，該處肺部也將失去進行氣體交換的功能。 |
| **順應性** | compliance | 指肺部擴張的難易程度，順應性越好，只要花少許力氣就能讓肺部擴張；相反的，若因病變使得順應性變差，要使肺部擴張就要花費更高的能量，呼吸就會比較費力。 |
| **菲克原則** | Fick principle | 用來計算心臟輸出量的原則，假設心臟所輸出的血氧總量，應等於組織消耗氧氣的總量加上剩餘的血氧總量。可藉由測量動靜脈血氧濃度差及二氧化碳排出量來計算所得到心臟輸出量。 |
| **喉咽反射或稱嘔吐反射** | gag reflex | 在碰觸一個人軟顎、舌根或咽部後側時所引發的正常反射動作，通常在重度意識昏迷時才會消失，常引起劇烈嘔吐導致吸入性嗆傷。 |
| **低二氧化碳症** | hypocarbia or hypocapnia | 指血中二氧化碳偏低，通常發生在過度換氣之後。 |
| **低氧血症** | hypoxemia | 動脈血中的含氧量過低，可造成組織缺氧。 |
| **缺氧** | hypoxia | 特別是指組織內的含氧量過低，會導致組織細胞死亡。 |
| **肺內壓力** | intrapulmonic pressure | 指肺泡內的氣體壓力，可由呼吸道測得的壓力來估計。 |
| **胸內壓力或稱肋膜腔內壓力** | intrathoracic pressure | 指胸腔內的壓力，指介於肺部之外及胸壁之內的空間的壓力，亦即肋膜腔內的壓力，可將偵測器直接伸入肋膜腔內測得。 |
| **每分鐘通氣量** | minute volume | 1分鐘之內總共吸入或呼出的氣體總量，假設呼吸均勻規則的情況之下，每分鐘通氣量等於潮氣容積乘以呼吸速率，若呼吸不規律，則每分鐘通氣量必須實際測量才能取得。 |
| **生理死腔或稱生理性無效腔** | physiological dead space | 為解剖性無效腔加上因病變而無法進行氣體交換的所有肺泡空間的總和，生理性無效腔的比例越大，呼吸的效率越差。 |
| **肺通氣或稱肺換氣** | pulmonary ventilation | 單純指氣體經由呼吸道進出肺部的過程，不涉及氣體交換的問題，因此只要測量壓力、容積和速率即可掌握。換氣因需求的不同而有過度或不足等問題。 |
| **呼吸** | respiration | 指氧氣和二氧化碳交換的動作，包含肺部交換與組織交換，也包括換氣的動作，是所有氣體交換功能的總稱。 |
| **潮氣量** | tidal volume | 單次呼吸所吸入或呼出氣體的量。必須在不刻意用力或憋氣之下所測得。 |

## 📖 內文重點整理

### 📙 呼吸生理學

#### 📘 呼吸的機轉

呼吸可分為外呼吸及內呼吸兩個階段。所謂外呼吸是指吸入的空氣在肺部與微血管內血液之間的氣體交換，內呼吸則是指在其他器官的微血管內，血液與組織細胞間的氣體交換。

呼吸的動作可以用流體力學的原理來說明。氣體會自高壓力、高濃度的區域往低壓力低濃度的區域流動。

- 大氣壓力：環繞在周邊空氣所具有的壓力，海平面高度約為 760mmHg。
- 肺內壓 (intrapulmonic pressure)：肺泡內的氣壓，約在 760mmHg 上下。隨胸部擴張降低（吸氣），壓縮升高（呼氣）。
- 胸內壓 (intrathoracic pressure)：肋膜腔內所測得壓力，正常情況略小於大氣壓（約 751~754mmHg）。

胸部和肺部的擴張靠的是呼吸肌的收縮，包括內外肋間肌以及膈肌。吸氣時膈肌收縮加大胸腔上下徑，內外肋間肌收縮撐出前後徑及左右徑；呼氣時則是被動回彈。

- 順應性或柔軟度 (compliance)：胸部及肺部擴張及縮小的容易程度。順應性越好越容易擴張；若因疾病（如氣喘、肺氣腫、肺水腫）導致下降，吸氣會變吃力。
- 消耗能量：正常安靜呼吸約占全身耗能 3%。在缺乏肺泡表面活性劑 (surfactant)、呼吸道阻力上升、肺順應性下降時，耗能可高達 33%。此時會使用輔助呼吸肌 (accessory muscle，如頸、背、腹部肌肉)。

- 呼吸速率：成人在休息情況下每分鐘呼吸 12~20 次。
- 潮氣容積 (tidal volume)：成人平均約為 500~600 毫升。其中 150 毫升分佈在無效腔，進入肺泡的只有 350~450 毫升。
- 無效腔：解剖性無效腔（無氣體交換功能的呼吸道）與生理性無效腔（包含因病變失去氣體交換功能的肺泡）。在肺氣腫等情況，生理性無效腔可高達解剖性的 10 倍。
- 餘容積 (residual volume)：用力呼氣後殘留在肺泡內的氣體，約 1,000~1,200 毫升，需 16 次以上呼吸才能完全更新。
- 最大吸氣容積 (inspiratory reserve volume)：正常吸氣後再用力吸入的最大氣體量，約 2,000~3,000 毫升。
- 最大呼氣容積 (expiratory reserve volume)：正常呼氣後再用力呼出的最大氣體量，約 1,200 毫升。

- 肺容量 (pulmonary capacity) 組合
  - 吸氣量 (inspiratory capacity)：潮氣容積 + 吸氣儲備容積，約 3,500 毫升。
  - 功能餘量 (functional residual capacity)：呼氣儲備容積 + 餘容積，約 2,300 毫升。
  - 肺活量 (vital capacity)：潮氣容積 + 吸氣儲備容積 + 呼氣儲備容積，約 4,600 毫升。
  - 全肺量 (total lung capacity)：肺活量 + 餘容積，約 5,800 毫升。

- 每分鐘通氣量 (minute volume)：潮氣容積 × 呼吸速率。
- 每分鐘肺泡通氣量 (minute alveolar ventilation)：(潮氣容積 - 無效腔) × 呼吸速率。

> ### 💡 核心觀念 ‧ 臨床實務
> - 肺泡表面活性劑降低氣液界面表面張力，使肺泡易打開；產量不足時需更高壓力差。
> - 氣流阻力主要在上呼吸道（鼻腔占 50%，口咽喉氣管占 20~30%）；支氣管收縮（如氣喘）會大幅增加阻力，使呼吸費力。
> - 空氣為混合氣體，壓力單位為 torr 或 mmHg (1torr=1mmHg)。海平面大氣壓 760mmHg (1 atm)。乾燥空氣中氮氣佔 78.62% (分壓 597mmHg)，氧氣佔 20.84% (分壓 159mmHg)。肺泡中因水蒸氣等因素組成不同。

#### 📘 肺部的循環與氣體交換

缺氧血回右心，經肺動脈入肺，在肺泡微血管進行交換。富氧血經肺靜脈回左心，經主動脈至全身。肺泡每天重複充填排空超過 15,000 次，休息時細胞總耗氧約 200毫升/min。

- 擴散動力：氣體壓力差。正常離開肺部時，肺泡與血液的氧分壓接近 80~100 mmHg，二氧化碳為 35~40 mmHg。
- 擴散阻力：肺泡壁塌陷（肺氣腫）會減少擴散總面積；肺水腫會使擴散膜增厚。

- 氧氣運輸：100毫升血液中，直接溶解僅 0.3 毫升，19.7 毫升 (98%) 由血紅素攜帶。
- 血紅素飽和度：在氧分壓 80~100mmHg 時飽和；10~60mmHg 時增加最快，大於 60mmHg 增加有限。靜脈血氧分壓約 40mmHg，飽和度 75%。
- 二氧化碳運輸：8% 溶於血漿，20% 和蛋白質結合 (碳胺血紅素 carbamino hemoglobin)，72% 以碳酸根離子 (HCO3-) 型式存在。

> ### 💡 核心觀念 ‧ 臨床實務
> - 菲克原則 (Fick principle)：組織獲得足夠氧氣需滿足：正常呼吸、高氧分壓、正常氧氣擴散、足夠血流/心臟功能/順暢血管、健全微血管、正常pH與體溫。

#### 📘 呼吸的調控

- 呼吸中樞位於延腦兩側 (吸氣、呼氣中樞) 及橋腦，控制基本韻律。
- 迷走神經將胸腹感覺傳回中樞；肺擴張牽引感知器傳訊至延腦，發出抑制訊號停止吸氣、開始吐氣。
- 化學接受器：延腦感知 PCO2 及 pH 值變化 (PCO2 增 5mmHg，通氣量增 100%)。周邊感受器 (頸動脈體、主動脈體) 監測動脈血氧 PO2。

> ### 💡 核心觀念 ‧ 臨床實務
> - 肺氣腫或慢性支氣管炎病人 PCO2 長期升高，感受器變不敏感，轉而倚賴低 PO2 維持呼吸動力 (低氧驅力)。

### 📙 呼吸病理生理學

#### 📘 呼吸道阻塞

- 清醒者多因食物哽塞。部分阻塞 (能講話、咳)、完全阻塞 (無法說話/換氣、掐頸徵象，數分鐘內窒息)。
- 意識不清者多因舌頭失去肌肉張力往後掉阻塞。
- 其他原因：聲門/聲門下水腫 (感染如會厭炎、過敏、熱傷害)、聲門/聲帶痙攣 (插拔管時)、喉部骨折 (皮下氣腫、吞嚥困難)。

#### 📘 吸入性嗆傷(aspiration)

- 易發生族群：意識程度下降、腸胃道阻塞造成嘔吐者。兒童占 80% (熱狗、花生)。成人多因假牙、意識不清、酒醉。
- 異物位置：60% 右側主支氣管，19% 左側，21% 喉部或聲帶。
- 傷害程度：視 pH 值、量、細菌污染而定。pH < 2.5 嚴重，pH < 1.5 常致命。胃酸造成化學性灼傷、肺泡塌陷、微血管通透性改變致肺積水。

### 📙 呼吸系統評估

- 呼吸速率：正常成人 12~20 次/分。<10 次考慮抑制 (藥物、神經、瀕死)，>20 次考慮缺氧、休克、窘迫。新生兒 >60 次為過快。
- 規則度：吸吐時間有一定比例韻律。
- 用力度：休息時不費力。過度用力代表呼吸困難；代償不足時意識改變、冒汗為呼吸衰竭。

- 姿勢：直立嗅吸、三腳架姿勢、半坐臥 (Semi-Fowler 15~45度)，避免平躺。
- 窘迫徵象：喘氣、發紺、鼻翼煽動、噘嘴/張口呼吸、使用輔助呼吸肌、肌肉凹陷 (胸骨上凹口、鎖骨上凹窩、肋間肌及肋下肌)。

> ### 📦 Box14-2 通氣不良的型態
> <p>缺氧(hypoxia)指無法滿足增加的氧氣需求或維持平衡。常見原因為通氣不良(hypoventilation)，包含機械性換氣不足與吸入氧量不足兩種型態，後者常有深快呼吸。</p>

### 📙 通氣與灌流的對應 (Ventilation vs Perfusion)

- 通氣 (V)：進出呼吸系統氣體量，約 4L/min。
- 灌流 (Q)：流經呼吸系統血流量，約 5L/min。
- 通氣灌流比 (V/Q ratio)：約為 0.8 (可約略估算為 1)。必須兩者同時足夠才能完成氣體交換。

#### 📘 通氣與灌流的不對等

- 分流 (shunt)：有血流無通氣 (V/Q趨近0)。如肺塌陷、肺炎、氣喘、ARDS、先天性心臟病右至左分流。給高濃度氧氣難以矯正低血氧。
- 無效腔 (dead space)：有通氣無血流。如肺動脈栓塞、COPD。會使二氧化碳不易排出。

| 解剖性分流 Anatomic shunt | 減少 | 增加 | 不變 |

### 📙 潮氣末二氧化碳(End-tidal CO2)

- 原理：吐氣末端呼出的全為肺泡內氣體，此時二氧化碳濃度達頂點 (EtCO2)，正常值 35~45 mmHg。
- 波形應用：
- 氣喘 (支氣管痙攣)：呼氣延長，二氧化碳緩慢上升，波形似鯊魚鰭。
- 過度通氣：潮氣末二氧化碳越來越低。
- 瀕臨呼吸衰竭：潮氣末二氧化碳越來越高，呼吸無力。
- 插管確認：若插在食道無波形；插管成功可測得二氧化碳。
- CPR品質：胸部按壓目標應使 EtCO2 達 10mmHg 以上，理想達 20mmHg。
- ROSC確認：回復自主心跳時，EtCO2 會突升至 40~50mmHg。

> ### 📦 Box14-3 潮氣末二氧化碳濃度圖儀之波形解析
> <ul><li><strong>正常情況</strong>：EtCO2值約為35~45mmmHg。</li><li><strong>偏高可能原因</strong>：換氣不足 (頭部外傷、藥物過量、中風等)、二氧化碳產生增加 (發燒、發抖)。</li><li><strong>偏低可能原因</strong>：通氣問題 (插管到食道內、呼吸道阻塞)、血流循環不足 (心跳停止、張力性氣胸)、V/Q不對等 (肺動脈栓塞)、二氧化碳製造減少 (低體溫)、採樣錯誤。</li></ul>

血氧濃度分析儀 (SpO2 monitor)：利用氧化血色素吸收較多紅外線、還原態血色素吸收較多紅光計算比例。正常值上限 99~100%，下限 93~95%；低於 90% (氧分壓 < 60mmHg) 為缺氧。

### 📙 情境解答

- 1. 意識喪失但有脈搏：放平病人，一人壓胸排除異物，準備三合一氧氣與抽吸，準備插管並以 laryngoscope/magill 夾除。
- 2. BVM給氧無效：依 SOP 若開放則報告指導醫師執行 non-OHCA 插管；若未開放則置入 SGA。

## ⚡ 重點一覽（公式、數值與衝刺要點）

### 🧮 公式彙整

- **每分鐘肺泡通氣量**：`(潮氣容積 - 生理性死腔) × 呼吸速率`
  - *說明*：衡量實際抵達肺泡進行交換的有效氣體量

### 🔢 重要數字 / 數值對照表

| 項目 | 關鍵數值 | 臨床說明 |
| :--- | :--- | :--- |
| **海平面大氣壓** | `760 mmHg` | 1 atm |
| **正常成人呼吸速率** | `12~20 次/分` | <10次或>20次需注意異常 |
| **成人潮氣容積** | `500~600 毫升` | 單次呼吸量，其中約150毫升在無效腔 |
| **最大吸氣容積** | `2,000~3,000 毫升` | 正常吸氣後再用力吸入量 |
| **最大呼氣容積** | `約 1,200 毫升` | 正常呼氣後再用力呼出量 |
| **餘容積** | `1,000~1,200 毫升` | 用力呼氣後殘留肺部的氣體 |
| **肺活量** | `約 4,600 毫升` | 潮氣容積+吸氣儲備+呼氣儲備 |
| **全肺量** | `約 5,800 毫升` | 肺活量+餘容積 |
| **通氣灌流比 (V/Q)** | `約 0.8` | 常約略估算為 1 |
| **正常潮氣末CO2 (EtCO2)** | `35~45 mmHg` | 反映肺泡內CO2濃度 |

### ⚡ 快速複習核心要點

- 通氣 (V) 與灌流 (Q) 需對等才能有效氣體交換，V/Q mismatch (如分流或無效腔) 會導致缺氧。
- 肺塌陷、氣喘、肺炎造成分流 (shunt)；肺栓塞、COPD 造成無效腔 (dead space)。
- 給予 100% 氧氣治療對生理性分流的 PaO2 提升變化不顯著。
- 缺氧的成因可由菲克原則分析：呼吸不佳、擴散異常、血流不足、血紅素異常。
- 呼吸窘迫的三腳架姿勢、半坐臥及輔助肌使用，皆顯示呼吸做功大幅增加。
- 氣喘的支氣管痙攣會在 EtCO2 呈現鯊魚鰭波形。
- CPR 按壓品質不佳時 EtCO2 會偏低 (<10mmHg)。
- EtCO2 可用於確認氣管內管位置、監測 CPR 品質、以及確認 ROSC。
- SpO2 低於 90% 時，對應氧氣分壓已低至 60mmHg 以下，急需給氧。
- 上呼吸道阻塞常見於意識不清者的舌根後倒，或異物、水腫所致。
