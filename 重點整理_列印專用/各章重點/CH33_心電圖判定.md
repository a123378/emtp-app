# CH33 心電圖判定

## 🎯 學習目標

- 瞭解心電圖的原理與基本操作。
- 學習系統性心電圖判讀的順序與重點。
- 熟悉各種常見的心律不整與傳導障礙。
- 瞭解常見及重要疾病之心電圖變化，以及其所代表的臨床意義。

## 🔑 關鍵詞句及定義

| 中文術語 | 英文術語 (English) | 定義與核心精神 |
| :--- | :--- | :--- |
| **P波** | P wave | 心房去極化過程所記錄得之訊號。 |
| **QRS複合波** | QRS complex | 心室去極化過程所記錄得之訊號。 |
| **T波** | T wave | 心室再極化過程所記錄得之訊號。 |
| **心軸** | axis | 指整體心臟電氣訊號傳導的方向，各個主要成分皆有其心軸，如P波代表心房去極化過程的方向、QRS代表心室去極化的方向，而T波則代表心室再極化的方向。 |
| **R波進展** | R wave progression | 胸前導程隨著胸骨右側第四肋間的V1導程移行至左腋下中線第五肋間V6導程的過程中，會有R波的大小將逐漸變大，而S波則逐漸變小乃至消失的情形。 |
| **R-S波交替** | R-S transition | 胸前導程由V1至V6的移行過程中，R波逐漸變大而S波逐漸變小，其中由R波小於S波轉變為R波大於S波的現象。正常情形下此交替通常發生在V3-V4兩導程間。 |
| **心房期外收縮** | atrial extra-systole | 指心房中有一個或多個區域在正常竇房節訊號傳導下來前便提早發出節律訊號，引發下游心房與心室的去極化以及再極化過程，也可稱Atrial premature contraction，APC/PAC。 |
| **心室期外收縮** | ventricular extra-systole | 心室中的部分心肌或區域在正常心律傳遞至心室前便發出節律訊號，引發心室過早的去極化及再極化，也可稱Ventricular premature contraction，VPC/PVC。 |
| **心房撲動** | atrial flutter | 心房內出現以迴繞機制(reentry mechanism)迴旋之波前(wavefront)，快速、反覆地引發心房的去極化，因此造成大小一致、規則而快速出現的P波，其速率約250~350下/分鐘間。 |
| **心房顫動** | atrial fibrillation | 心房顫動時心房內的迴繞機制(reentry)較之心房撲動更加快速且雜亂無章，速率通常大於350下/分鐘以上。在心電圖上呈現P波大小不一、速率極快，而P-P區間又長短不定的情形。心室速率常為130~150下/分鐘且R-R時距極不規則。 |
| **心室頻脈** | Ventricular Tachycardia, VT | 為心室節律連續而快速的出現，導致正常由竇房節發出的節律被掩蓋。特點為QRS複合波的寬度較由正常竇性節律傳下者為寬，速率往往超過200下/分鐘。 |
| **心室顫動** | Ventricular Fibrillation, VF | 在心室內出現許多紊亂的波前亂竄，造成心室去極化的過程雜亂無章，心電圖上可見到大小、寬窄不一的QRS波連續、快速地出現，速率通常大於300下/分鐘。幾無心輸出可言。 |
| **陣發性心室上心搏過速** | Paroxysmal Supra-Ventricular Tachycardia, PSVT | 指由房室節或以上所發出，規則而快速、連續的心律，包括AV nodal reentry tachycardia (AVNRT)、AV reentry tachycardia (AVRT)以及心房性心搏過速(atrial tachycardia)等節律。 |
| **房室傳導阻滯** | AV block | 意指心律訊號由心房經房室節及His傳導束傳遞至心室的過程中有所阻礙，臨床上造成傳導障礙的位置主要位於房室節附近，可分為一級、二級與三級三種。 |

## 📖 內文重點整理

### 📙 心電圖基本原理

心肌細胞與神經細胞相同，均為具有電氣生理活動的細胞。體表心電圖乃是以導電導極從身體表面記錄心臟整體的電器生理活動。

#### 📘 十二導程心電圖之組成與操作

十二導程心電圖乃由十個導電導極（包含六個胸前導極與四個肢體導極）所組成的十二個導程。

- 肢體導極：貼於兩側手腕及兩側腳踝，形成三個標準導程（Ⅰ、Ⅱ及Ⅲ）以及三個加強導程（aVR、aVL及aVF）。在額面（coronal plane）觀察，角度分別為0度、60度、120度、90度、負30度及負150度。
- 胸前導程：由人體橫於胸前的水平面（axial plane）來記錄。
- 六個胸前電極黏貼的位置：
  - V1：胸骨右側的第四肋間
  - V2：胸骨左側的第四肋間
  - V3：V2及V4間的中點
  - V4：左胸第五肋間的鎖骨中線處
  - V5：左胸第五肋間的前腋線（anterior axillary line）
  - V6：左胸第五肋間的中腋線（middle axillary line）

> ### 💡 核心觀念 ‧ 臨床實務
> - 熟悉心電圖十個導極的黏貼位置，特別是胸前導極的正確位置。
> - 避免將左、右手或上、下肢的導極貼反，以確保心軸和波形判讀正確。

#### 📘 心電圖各個組成分的認識

- P波：心房的去極化過程，由左心房與右心房的去極化電器活動所共同組成。正常P波寬度小於0.12秒，高度不超過2.5 mm。
- PR節段 (PR segment)：心房去極化完成後至心室去極化開始前的一個生理性延遲，主要由房室結所造成。
- PR區間 (PR interval)：由心房去極化開始至心室去極化開始的區間，正常為0.12~0.20秒。
- QRS複合波 (QRS complex)：心室的去極化過程。第一個向下的波折為Q波，第一個向上的波為R波，第二個向下的波則為S波。第二個向上的波命名為R'波。
- T波：心室完成去極化過程後的再極化過程。
- ST節段 (ST segment)：心肌缺血或梗塞時會出現向上或向下偏移的現象。

### 📙 系統性的心電圖判讀

- 心律之判定：判斷發號施令的源頭究係來自何處，通常由第二長導程(long lead Ⅱ)判讀。
- 心軸之計算：心軸代表心臟整體電生理訊號傳導的方向。正常心臟節律自竇房結發出後向左下方傳至房室結，心軸大抵指向左下。高瘦的人心軸可能偏右(vertical heart)，矮胖的人可能偏左(horizontal heart)。
- 各組成成分之解讀：觀察P波、QRS複合波以及T波的大小及形狀變化，推斷各心室潛在的病理變化。
- 各節段與區間之判讀：PR區間代表心房去極化至心室去極化間的傳導過程；ST節段代表心室去極化完成後至再極化開始前的間歇；QT區間與心室整體去極化與再極化的過程相關。

> ### 💡 核心觀念 ‧ 臨床實務
> - 完整的心電圖判讀包括：(1)心律之判定；(2)心軸之計算；(3)各組成成分之解讀；(4)各節段及區間之判讀。

### 📙 常見組成成分異常與心軸偏轉的相關問題與疾病

#### 📘 P波與QRS複合波-心房與心室之擴大與肥厚

- 1. 右心房擴大
  - 變化主要為P波變高(＞2.5mm)而寬度不變，形成P pulmonale。
  - 常見於導程Ⅱ、Ⅲ及aVF，偶而V1導程亦可見到。
  - 常見原因：先天性心臟病（ASD、肺動脈狹窄、法洛氏四重症候群）或肺部疾病（肺栓塞、COPD）。
- 2. 左心房擴大
  - 變化主要為P波變寬(＞0.12秒)，形成P mitrale。
  - P波變寬後可能形成兩個峰(hump)，中間有個缺口(notch)。
  - 胸前導程V1常見到雙向的P波(biphasic P wave)，第二個負向波寬度大於0.04秒，深度大於1mm。
- 3. 右心室肥厚
  - 胸前導程R-S的交替提早出現於V2-V3或V1-V2間，甚至V1導程R＞S。
  - 心軸右偏(＞100度)。
  - 可能出現心室肥厚的次發性再極化異常，T波倒轉及ST節段下降，主要出現於V1-V2。
- 4. 左心室肥厚
  - 心軸偏左(＜-30度)。
  - QRS的變化：V5的R波變高、V1的S波變深，aVL導程變高。
  - 左心室肥厚voltage criteria：胸前導程(V5/V6的R波+V1的S波＞35mm等)及肢體導程(aVL的R波＞13mm等)。
  - 嚴重時出現次發性再極化異常，ST節段下降和倒置的T波融合，常見於Lead I、aVL、V5和V6。

> ### 💡 核心觀念 ‧ 臨床實務
> - 右心房與左心房擴大差別：右心房是P波變高(P pulmonale)，左心房是P波變寬(P mitrale)。
> - 心室肥厚的次發性再極化異常有助於確認肥厚的嚴重程度，並需與心肌缺血鑑別。

### 📙 常見的節律異常

#### 📘 竇性節律異常

- 竇性頻脈：速率超過100下/分鐘。
- 竇性緩脈：速率小於60下/分鐘。
- 竇性心律不整 (sinus arrhythmia)：P-P區間不完全等距，差異性大於20%。

#### 📘 上心室節律異常

- 1. 心房性期外收縮 (APC)
  - 提早出現的P波，形狀與正常P波略有不同，PR區間通常較短。
  - 保有正常形態的QRS複合波及T波。
- 2. 心房顫動 (Af) 與心房撲動 (AF)
  - 心房撲動：速率250~350下/分，規則的鋸齒狀P波，心室反應依傳導比例(如2:1則為150下/分)通常規則。
  - 心房顫動：速率＞350下/分，P波大小不一且極不規則，心室速率極快(130~150下/分)且R-R時距極不規則。
- 3. 陣發性上心室頻脈 (PSVT)
  - 包括AVNRT, AVRT, atrial tachycardia。
  - 快而規則的窄QRS(通常＞180下/分)，P波可能埋在QRS內、緊接前/後，或呈倒立(inverted P wave)。
- 4. Junction節律
  - 房室結發出，通常因竇房結失效或傳導阻斷。速率約40下/分(跳脫節律)。
  - QRS前無P波，QRS正常窄波；可能有VA傳導造成倒立P波。

#### 📘 心室性節律異常

- 1. 心室性期外收縮 (VPC)
  - 提早出現，QRS寬大畸形(＞0.12秒)，前方無對應P波。
  - 可分為單發、多發(multiform)、二連波(bigeminy)、三連波(trigeminy)、couplet等。
- 2. 心室頻脈 (VT)
  - 連續快速的心室節律，速率約200下/分，寬QRS波。
  - 可分為單一形態(monomorphic)與多形性(polymorphic)。Torsade de pointes是特殊多形性VT，類似sine wave，與QTc延長有關。
- 3. 心室顫動 (VF)
  - 心室內紊亂波前，大小、寬窄不一的QRS連續快速出現(＞300下/分)，無P波與T波。
  - 毫無有效心輸出，病人立即暈厥。

### 📙 常見傳導異常與障礙

#### 📘 房室結傳導阻斷 (AV block)

- 一級房室結傳導阻斷：P-R區間固定延長(＞0.20秒)，每一個P波都能下傳產生QRS。
- 二級房室結傳導阻斷：
  - Mobitz第一型 (Wenckebach現象)：P-R區間逐漸拉長，直到一個P波無法下傳QRS。阻斷在房室結，QRS多為窄波。
  - Mobitz第二型：P-R區間固定，突然出現P波無法下傳QRS。阻斷較低(His bundle)，QRS常為寬波(BBB形態)。
- 三級(完全)房室結傳導阻斷：P波與QRS波各自獨立、互不相干(房室解離 AV dissociation)。P-P規則，R-R規則。

#### 📘 心室傳導束傳導阻斷 (Bundle Branch Block, BBB)

- 判定標準：QRS＞0.12秒為完全傳導阻斷，QRS＜0.12秒為不完全。
- 1. 右心室傳導束阻斷 (RBBB)
  - V1及V2出現RSR'型態(兔耳朵)。
  - V1-V3出現次發性ST下降與T波倒轉。
- 2. 左心室傳導束阻斷 (LBBB)
  - 導程Ⅰ及V4-V6出現寬的、有notch的RR'波，失去正常起始小q波。
  - V1-V3呈現rS或QS型態。
  - 導程Ⅰ、V4-V6出現ST節段下降與不對稱T波倒轉(次發性變化)。

### 📙 心肌缺血與心肌梗塞的心電圖變化

#### 📘 心肌缺血的變化

體表心電圖主要為ST節段下降(ST depression)及T波倒置(T inversion)。需有解剖學上相關性的連續兩個或以上的導程出現一小格以上的變化方有意義。

- V1-V4：左心室前壁/中膈，由左前降枝(LAD)供應。
- Ⅱ、Ⅲ、aVF：左心室下壁，由右冠狀動脈(RCA)供應。
- Ⅰ、aVL、V5-V6：左心室側壁/高位側壁，由左迴旋支(LCx)供應。

#### 📘 心肌梗塞的判讀

- 超急性T波 (hyperacute T wave)：阻塞後10~30分鐘出現，T波高尖，代表嚴重缺血。
- ST波段上升 (ST elevation)：20~40分鐘後出現，代表全壁層心肌受損(STEMI)。
- 病理性Q波 (pathological Q wave)：代表心肌細胞不可逆死亡，出現後往往終身存在。
- 對應變化 (reciprocal changes)：心肌梗塞區域對側導程出現相反的ST段下降。例如前壁梗塞時下壁導程ST下降。
- 後壁梗塞：V1-V2呈現ST下降、T波倒置、高R波。常與下壁梗塞同時出現。

#### 📘 堵塞型心肌梗塞(OMI)的概念

泛指與冠狀動脈阻塞相關的任何心電圖變化，包括Wellens' syndrome、左支傳導阻滯(Sgarbossa criteria)、左主冠阻塞(廣泛ST下降併aVR上升)等。

### 📙 情境解答與問題交流

> ### 💡 核心觀念 ‧ 臨床實務
> - 下壁心梗(Ⅱ, Ⅲ, aVF ST上升)併V1-3 ST下降及高R波：考慮下壁合併後壁梗塞。
> - 下壁心梗病人若血壓偏低，應避免使用NTG及嗎啡。
> - 下壁心梗應加做右側心電圖(V4R)，若ST上升代表右心室梗塞。此時若肺部清澈且休克，可考慮給予適當靜脈輸液增加前負荷。
> - LBBB與RBBB判定需看QRS寬度，兔耳朵型態不一定就是BBB，若是偶發出現的寬QRS，可能為VPC。
> - 心電圖上QRS波均很小(＜5mm)可懷疑心肌減少或遮蔽效應(積液、COPD、肥胖)，大範圍QS pattern可懷疑陳舊性心梗或心衰竭。

## ⚡ 重點一覽（公式、數值與衝刺要點）

### 🔢 重要數字 / 數值對照表

| 項目 | 關鍵數值 | 臨床說明 |
| :--- | :--- | :--- |
| **心電圖小格與大格** | `1mm = 0.04秒，5mm = 0.2秒` | 橫軸代表時間。縱軸1mm = 0.1mV。 |
| **正常PR區間** | `0.12~0.20秒` | 代表心房去極化至心室去極化開始的時間。 |
| **正常QRS寬度** | `小於0.12秒` | 大於0.12秒代表完全心室傳導阻斷(Complete BBB)。 |
| **正常P波高度與寬度** | `寬度<0.12秒，高度<2.5mm` | 變高為右心房擴大，變寬為左心房擴大。 |
| **竇性節律正常速率** | `60~100下/分鐘` | 由竇房結發出。 |
| **左心室肥厚Voltage criteria** | `V5/V6 R波 + V1 S波 > 35mm` | 其中一種常用診斷標準。 |

### ⚡ 快速複習核心要點

- 心律判讀的第一步是確認節律是否由竇房結發出，觀察P波是否存在及與QRS的關係。
- 右心房擴大看P波變高(P pulmonale)，左心房擴大看P波變寬(P mitrale)。
- 心室肥厚除了看電壓高低外，注意是否出現ST下降與T波倒置的次發性再極化異常。
- 心房撲動呈規則鋸齒狀P波，心房顫動則P波不規則、心室R-R間距極不規則。
- 一級房室阻斷PR延長固定；二級Mobitz I型PR漸長後脫漏，Mobitz II型PR固定突發脫漏；三級房室解離。
- RBBB在V1/V2呈RSR'兔耳朵型態，LBBB在V5/V6呈寬大有notch的RR'波。
- 急性心肌梗塞演進：超急性T波 → ST波段上升 → 病理性Q波 → T波反轉 → ST回到基準線。
- 判讀ST-T變化需尋找解剖相關連續兩個導程：V1-V4(前壁)、Ⅱ/Ⅲ/aVF(下壁)、Ⅰ/aVL/V5-V6(側壁)。
- 下壁心梗常合併右心室梗塞及後壁梗塞，應加做右側心電圖(V4R)，並小心使用NTG以免血壓過低。
