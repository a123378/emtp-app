# CH05 救護技術員的職業安全與傳染病防治

## 🎯 學習目標

- 能了解職業傷害的定義與相關危險因子。
- 能了解救護技術員常見的職業傷害以及預防方式。
- 能了解交通運輸相關的安全問題。
- 可以利用事故風險矩陣來分析救護車事故的原因並提供因應之道。
- 能了解如何事前預防職業性感染。
- 能了解救護技術員常見的職業性感染與防護方式。

## 🔑 關鍵詞句及定義

| 中文術語 | 英文術語 (English) | 定義與核心精神 |
| :--- | :--- | :--- |
| **職業災害** | Occupational Disaster | 勞工因執行職務而導致傷害，稱為職業災害(包括勞工在上、下班途中，從日常住處往返工作場所應該經過的途中發生事故)。 |
| **職業病** | Occupational Disease | 勞工因執行職務暴露在一些危險因子中導致身體產生疾病，需經醫師診斷。 |
| **職業傷害** | Occupational Injury | 包含職業災害、職業病與職業相關的死亡。 |
| **救護運輸的安全** | Ambulance Transportation Safety | 指救護相關運輸工具的安全相關議題，包含原因、相關法律、交通事故、死亡等。 |
| **職業性感染** | Occupational Infection | 工作中會暴露血液、感染性體液的職業，經由暴露途徑為於病源體帶入人體內而感染。 |
| **全面性防護** | Universal Precaution | 是指為減少工作人員因為照護病人而感染特殊疾病，採取特定體液與血液隔離措施，即使在非執行醫療處置的情形下，並假設所有病人都是潛在的感染源。 |

## 📖 內文重點整理

救護技術員的工作環境充滿了不確定，有可能是馬路邊的車禍現場、病人的家中、或是化學災害的工廠。由於工作內容充滿未知，有一定的職業風險與傷害。救護技術員的職業傷害常見來自於救護車的車禍事件、精神急症病人的暴力相向、不良的健康狀態、工作壓力、職業倦怠、輪班的工作性質與不良的睡眠品質。

### 📙 職業傷害

職業傷害是指勞工因執行職務而導致傷害；而職業病是指勞工因執行職務暴露在一些危險因子中導致身體產生疾病，需經專科醫師診斷。依照作業場所可將危害因子分為五大類：物理性、化學性、生物性、人因工程、社會心理性。

#### 📘 救護人員的職業傷害概述

- 少有研究探討緊急救護人員中非致命性的傷害。其中依職業傷害和疾病分類手冊的編碼分類，33％與「身體過度使用和勞累」、21％與「接觸有害物質或環境」、18％與「和物體或設備接觸碰撞」有關。
- 最常見的非致命性傷害的診斷為扭傷/拉傷占38％、挫傷/擦傷占17％、撕裂/穿刺傷占14％。其中脖子和背部是最常受到傷害的部位(31％)。
- 在醫療照護人員中，常見的為腰椎椎間盤突出、膝關節骨關節炎、肌腱(腱鞘)炎；都是由於長時間負重與蹲姿、重複上抬上舉所引起的。
- 美國職業安全與健康研究所統計資料指出，過度疲勞是最常見的傷害事件(31％)，其他常見傷害事故有暴力(18％)、有害暴露(15％)與救護車事故(15％)。
- 職場安全文化與緊急救護人員的職業傷害相關，包含工作安全的氛圍、團隊合作的氛圍、安全的管理、工作條件、壓力辨識與工作滿意度。

#### 📘 救護技術員常見的職業傷害與管理

疾病「三段五級」的初段預防中，健康促進與特殊保護同等重要。常見的職業傷害如下背痛、救護車意外相關疾病、針扎與感染。

- 下背痛
  - 抬病人時，應屈膝、彎曲髖關節來代替彎腰。
  - 病人重心應靠緊自己身體，以腿力抬起病人，而不是以腰力抬起病人。
  - 行進時小心週遭事物，應小步前進，不可以背對著前進。
  - 引進電動擔架床後，相關的職業傷害自61.1/100人降至28.8/100人，職業傷害風險下降了47％。
- 職場暴力
  - 53~90％的緊急救護人員曾發生過職場暴力事件，其中口頭或身體的暴力占67％。
  - 多數施暴者是病人本身，其次是病人家屬/友人。
  - 近幾年來，消防署與醫療指導醫師學會大力推廣「危機處理小組(CIT)」的應變課程。
- 緊急救護人員的職業死亡
  - 全職緊急救護人員的死亡率超過一般工作人員。
  - 大多數緊急救護人員的死亡與交通事故相關，包含車輛撞毀或者飛機墜毀。

#### 📘 救護運輸的安全

- 救護車意外事故不但會造成救護時效的延誤，也會造成人員傷亡。
- 在緊急救護人員的職業相關死亡中，運輸相關事故占59％。
- 安全的救護車駕駛原則：
- 適當的救護優先派遣。非危急個案一般反應即可。
- 安全駕駛。
- 完整良好的救護車保養。
- 惡劣天候，小心駕駛。
- 與同仁充分合作，安全前往現場，安全離開現場。
- 適當的運用閃光燈與鳴笛。
- 安全通過路口。
- 注意現場停車安全，必要時做安全警戒。
- 利用哈頓(Haddon's)模型的事故風險矩陣分析車禍事故原因，依駕駛因素、車輛因素、環境因素，分為事故前、事故中與事故後。

### 📙 救護技術員的職業性感染

救護技術員的日常勤務直接接觸各種急重症病人，因而暴露在可觀的傳染性疾病威脅之中。針對人員、物品與環境的清潔消毒，應制定規範，使得人員可以在緊急狀況中有所依循。

#### 📘 人員

- 1. 防護措施
  - 標準防護措施適用於所有勤務，救護人員均須配戴外科口罩。
  - 接觸血液、體液等狀況，需戴上手套。遇大量血液噴濺，應戴上護目鏡。
  - 接觸傳播疾病(如疥瘡)應戴手套，若需大面積接觸病人，應穿著拋棄式防護衣。
  - 空氣傳播疾病(如開放性肺結核、麻疹及水痘)需配戴N95口罩。
  - 飛沫傳播疾病(如流行性感冒)需配戴外科口罩。
  - 力行「全面性防護(universal precautions)」，假設所有病人都是潛在的感染源。
- 2. 健康管理
  - 人員到職時提供職前健康檢查(B型肝炎抗體、水痘及麻疹抗體、胸部X光)。
  - 在職員工每年健康檢查至少一次。
  - 意外曝觸血液(體液)感染源，應儘快安排人員到醫療院所檢查，若需預防性服藥，應立即接受治療。
- 3. 在職教育
  - 參加感染管制主題講習，安排防護實務演練。
  - 若發覺有異常感染或群聚感染的可能，應通報當地衛生主管機關或疾病管制署。

| 項目 | 建議 |
| :--- | :--- |
| 病灶部位 | 觸摸血液，體液，分泌物，排泄物和受污染的物品後；在取下手套後；接觸不同病人之間。 |
| 手套 | 用於接觸血液，體液，分泌物，排泄物和污染物；用於接觸粘膜和不完整的皮膚。 |
| 防護衣 | 當進行預計會發生和血液/體液、分泌物和排泄物染污的衣服、暴露的皮膚接觸的醫療程序和照護活動時。 |
| 口罩，護目鏡，面罩 | 在醫療程序和照護活動中可能產生血液、體液，或分泌物飛濺時，尤其是抽痰、氣管插管。 |
| 針和其他銳器 | 不要回套、彎曲、折斷或用手操作使用過的針頭；如果需要回套，只能使用單手技術；將使用過的尖銳物放置在防刺穿容器中。 |
| 病人復甦 | 使用面罩、復甦球或其他通氣裝置以防止接觸口腔和口腔分泌物。 |

> ### 💡 核心觀念 ‧ 臨床實務
> - Q：值勤中不小心針扎，該如何處置？其中梅毒、HIV與肝炎病毒事後該如何處置與追蹤？

#### 📘 物品

- 防護用具於勤務結束時卸除，以感染性廢棄物處理。
- 針具使用後勿回套，直接丟入尖銳物品收集筒(約八分滿時蓋上上蓋)。
- 可重複使用的急救設備，須先以流動的清水洗去殘留的血液、體液。

| 裝備名稱 | 處理方式 |
| :--- | :--- |
| 附有腳架滑輪之擔架床 | 去除殘留血跡後，以1,000ppm濃度次氯酸納溶液擦拭。 |
| 攜帶式及固定式氧氣組 | 以1,000ppm濃度次氯酸納溶液或75％酒精擦拭。 |
| 八號抽吸導管及十四號抽吸導管 | 原則上使用後即丟棄。 |
| 可丟棄式手套、外科口罩 | 使用後丟棄。 |
| 毛毯或被單 | 一般病人個別清洗；疑似疥瘡以塑膠袋封口包裝，靜置14天後清洗。 |

#### 📘 環境

- 開放性肺結核個案，勤務結束後打開車窗通風至少1小時。
- 以1,000ppm濃度次氯酸鈉溶液(漂白水)擦拭病人及救護人員接觸過的環境。30分鐘後要再用清水擦拭一遍。
- 無法使用次氯酸鈉溶液擦拭的部分，可改用濃度75％的酒精擦拭。
- 救護車內部應定期消毒，建議每週一次完整消毒(乾式清消後濕式清消)。

| 消毒劑 | 稀釋比例 |
| :--- | :--- |
| 漂白水(Antiformin，5~6％) | 1:50(稀釋50倍)，200cc加10公升水 |
| Klorsept 1.67g/錠 | 1錠加1公升水 |
| PRESEPT 2.5g/錠 | 1錠加1公升水 |

> ### 💡 核心觀念 ‧ 臨床實務
> - Q：還記得發燒病人TOCC的詢問是指那些？該如何查詢目前各區疫情的狀況呢？

【情境解答】標記HIV病人隱私權不得侵犯，且可能使EMT面對未知病人防護鬆懈。真正能減少被感染風險的是標準防護措施(全面性防護)與職業曝露後預防(OPEP)。

【問題交流 - 肌肉扭傷與下背痛】
肌肉扭傷處置原則採RICE (Rest休息, Ice冰敷, Compression壓迫, Elevation抬高患處)。
下背痛發生後建議臥床休息，工作時穿戴背架或束腹，減少腰椎負荷。

【問題交流 - 肺結核】
肺結核藉由空氣傳染，外科口罩無法抵擋，需使用N95口罩。95%的人初感染時未發病，但有終身再活化(reactivation)危險。

### ⚡ 快速複習核心要點

- 救護技術員有較高的風險會有相關職業傷害與職業病；常見危害因子：物理性、化學性、生物性、人因工程、社會心理性。
- 最常見的非致命性傷害因子為「身體過度使用和勞累」與「接觸有害物質或環境」。
- 最常見職業傷害診斷為扭傷/拉傷、挫傷/擦傷與撕裂/穿刺傷，脖子和背部是最常受傷部位。
- 最常見的職業相關死亡為交通事故，救護車安全駕駛非常重要。
- 救護運輸交通事故依風險矩陣分為駕駛、車輛、環境因素；時間點分為事前、事中、事後。
- 救護勤務中應採「全面性防護(universal precaution)」，假設所有病人都是潛在感染源。
- 扎傷後應以肥皂及水清潔，24小時內通報，並盡速於72小時內尋求暴露後預防性投藥(OPEP)。
- 處理開放性肺結核、麻疹、水痘等空氣傳播疾病時，須戴N95口罩。
- 環境與車輛消毒常使用1,000ppm漂白水擦拭，無法使用漂白水時使用75%酒精。
- 尖銳物品使用後「絕不可回套」，應直接丟棄於防穿刺的尖銳物品收集筒(八分滿即丟棄)。
