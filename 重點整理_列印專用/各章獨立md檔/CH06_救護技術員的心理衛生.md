## 📖 內文重點整理

### 📙 心理健康

每個人都應該擁有健康的權利。世界衛生組織 (WHO) 定義健康是一個在生理層面、心理層面及社會層面的安寧美好狀態，包含維持正常狀態，能實現自己的潛能、面對生活的壓力、工作能獲得成效與卓越表現，以及有能力為社會貢獻己力，不僅僅是沒有疾病。

緊急救護技術員在災難或救護的現場，往往是面對衝擊的最前線，必須處變不驚，需要擁有正確的學理觀念與技能，以及具備良好的心理素質與復原力。

心理健康提倡三級預防理論：

- 初級預防(primary prevention)
  - 問題不明顯或未發生，是防患於未然，預防疾病發生。可以做的為：壓力調適、民眾心理健康教育、社區心理衛生中心等。
- 次級預防(secondary prevention)
  - 早期發現問題，早期治療，目的在於降低風險、病情慢性化。資源包括張老師、生命線等機構。
- 三級預防(tertiary prevention)
  - 問題已發生，給予適當治療與定期追蹤照顧(復健)，將傷害降到最低，協助個案回到健康生活。資源包括康復商店、庇護工場、日間留院等。

| 預防策略 | 預防方法 |
| :--- | :--- |
| 一級 (初段預防) | 健康教育、健康促進、特殊保護、CIT介入 |
| 二級 (初段預防) | 疾病控制 |
| 三級 (次段預防) | 早期診斷、早期治療 |
| 四級 (三段預防) | 限制殘障、慢性病追蹤管理 |
| 五級 (三段預防) | 復健 |

馬斯洛需求理論(Maslow's hierarchy of needs)由低至高為：

- 生理需求(physiological needs)：最基本讓自己活下去的層次(食物、水、空氣)。
- 安全需求(safety needs)：追求人身安全、免遭受痛苦與疾病。
- 愛與歸屬(love and belonging needs)：追求友情、愛情及歸屬感。
- 自尊(esteem needs)：追求成就感、個人價值、名聲與地位。
- 自我實現(Self-actualization)：最高層次，追求真善美的人生境界。

### 📙 精神、健康與疾病

精神疾病也是大腦疾病。精神包含情緒、行為、認知及生理驅力四個層面；疾病是生理功能異常的狀態，泛指導致疼痛、痛苦、失能或死亡。

大腦分成四個皮質區：

- 頂葉(parietal lobe)：感覺與運動行為、訊息整合、空間知覺。
- 枕葉(occipital lobe)：視覺空間處理。
- 顳葉(temporal lobe)：聽覺、認知、情緒、記憶。
- 額葉(frontal lobe)：情緒、認知、注意力、問題解決、推理能力、行為策劃。

美國精神醫學會的 DSM-V 定義精神疾病為一種症候群，個體在認知、情緒調節或行為上有顯著困擾，且表現在精神功能障礙。

可透過以下五個層面評估精神症狀：

- 情感反應(Affect)：持續憂鬱、焦慮、易怒、暴躁等情緒。
- 行為(Behavior)：行動遲緩、坐立不安、自傷傷人、怪異行為、暴力行為、酒精藥物濫用等。
- 認知(Cognition)：妄想、幻覺、自殺意念、記憶力減退等。
- 生理驅力(Drive)：失眠、食慾增加或減退、性慾增加或減退等。
- 身體症狀(Somatic symptoms)：情緒導致身體不舒服或檢查不出原因的身心症狀。

#### 📘 消防人員傷亡事件與心理健康

救護與救災人員長期暴露在壓力與創傷事件中，經歷被救者生命流逝、拯救孕婦兒童未果及同儕死傷等，都可能造成憂鬱、焦慮或 PTSD 等心理疾病。

#### 📘 常見的精神疾病

#### 📘 情緒障礙症

- 憂鬱症(Depressive Disorder)
  - 主要症狀為悲傷、空虛、易怒、對任何事物無法感受到快樂，並伴隨身體和認知功能的變化(疲累、失眠)。
- 焦慮症(Anxiety Disorder)
  - 包含過度擔憂未來，出現恐懼、焦慮及迴避行為。恐懼是當下對立即危險的反應；焦慮是預期受威脅的情緒。
- 躁鬱症(Bipolar Disorder)
  - 個案會在不同時期出現「狂躁」與「憂鬱」兩種情緒。
  - 狂躁期：睡眠短、精力充沛、說話快、自信、注意力不集中、過度投入無節制行為。
  - 憂鬱期：失眠/嗜睡、食慾改變、遲緩或焦躁、覺得無助無望、自殺意念。

#### 📘 創傷及壓力相關障礙症

當經歷嚴重創傷事件後，常出現喪失興趣、憂鬱、憤怒、解離等症狀。

| 診斷 | 病因起源 | 現象與行為 | 症狀維持時間 |
| :--- | :--- | :--- | :--- |
| 創傷後壓力疾患(PTSD) | 目擊或經歷創傷事件 | 創傷經驗再現、過度警覺、逃避或麻木、出現與創傷事件相關的負向認知與情緒 | 1個月以上 |
| 急性壓力症(ASD) | 目擊或經歷創傷事件 | 害怕、恐懼、無助感、無法經驗到正向情緒、失去現實感、無法回憶起創傷事件 | 3天到1個月 |
| 適應障礙症(AD) | 壓力源產生 | 擔心焦慮、失眠、心情低落、逃避行為、人際相處困難 | 6個月內 |

#### 📘 創傷後壓力疾患與急性壓力症的醫療協助

首選為「心理治療」，如認知行為治療(CBT)、眼動減敏與歷程更新治療法(EMDR)等。藥物治療常用抗憂鬱劑或血清素受體阻斷劑(SSRIs)。

#### 📘 自殺 (Suicide)

當個案有明確的自殺計畫或致命性工具取得的可近性時，需要立即介入防範。自殺高風險因子包含：老年人、男性、獨居者、喪偶失業者、嚴重生理疾病者、曾有自殺行為、精神疾病患者、無社會支持者等。

> - Q：當壓力存在且超過自己可以負荷時，會藉由藥物或酒精麻痺或使自己產生興奮感，如何定義物質成癮過程？嚴重的物質使用障礙症會出現哪兩種症狀？

#### 📘 物質使用障礙症

成癮是一個刺激對中樞神經產生反應，透過多次刺激與情緒連結產生的制約行為。

- 藥物成癮原因
  - 個人因素：人格發展偏差、好奇、尋求刺激、缺乏自信等。
  - 環境因素：家庭不和諧、生活習慣偏差等。
  - 教育因素：價值觀、適應不良等。
  - 社會因素：社會風氣、生活空間等。
- 嚴重的物質使用障礙症兩種症狀
  - 耐受性 (tolerance)：欲達到效果，使用量會越來越多。
  - 戒斷症狀 (withdrawal)：停止使用會產生負面的生理或心理反應，如抽搐、嘔吐、發抖、失眠。

#### 📘 睡醒障礙症

- 失眠症 (insomnia disorder)：難以入睡、維持睡眠困難。
- 嗜睡症 (hypersomnolence disorder)：睡眠超過7小時仍有嗜睡感、體力難以恢復。
- 日夜節律睡—醒障礙症 (circadian rhythm sleep-wake disorder)：日夜節律改變造成時間不協調，常見於輪班人員。

### 📙 疾病預防

面對壓力源時，可透過腹式呼吸、戶外運動、時間管理等方法紓解。也可透過「簡式健康量表(BSRS-50)」或「台灣人憂鬱症量表」檢視心理狀態。

- 察覺異常行為的7項指標
  - 負向情緒明顯增加且持續超過兩週。
  - 憂鬱情緒，嚴重影響日常生活。
  - 焦慮情緒超過1個月無法放鬆。
  - 創傷事件再經驗。
  - 自殺的意念或行動。
  - 物質濫用問題。
  - 失眠或嗜睡功能減損。
- 幫助救護技術員維持心理健康的7種方法
  - 支持系統的建立 (家人、朋友、同事)。
  - 與人相處保有彈性、培養正向思考。
  - 接納自己、欣賞自己的優點。
  - 適時調適心情、正念習慣的養成。
  - 培養樂觀的態度、有意義生活的建立。
  - 運動習慣的養成。
  - 接受生活中的挑戰。
- 消防局改善政策
  - 合理的工作時數與工作量。
  - 員工協助方案 (EAPs)。
  - 正向回饋。
  - 關懷與陪伴。
  - 介接社會安全網。
  - 參與外部減壓團體或工作坊。
  - 多元公平共融 (DE&I)。

#### 📘 危機介入小組介入時機與辨識案件性質

啟動危機介入小組 (CIT) 後，應辨識六種類型個案：

- 一般內外科疾病者：行為異常可能是低血糖、電解質失調導致。
- 單純暴力者：非精神病，應交由警政處理。
- 精神疾病病人：切勿臆測診斷，與其建立關係、觀察是否服藥。有自傷/傷人威脅則需防範。
- 物質濫用者：反應遲緩、無法控制行為，應拉開距離並請警政協助。
- 自殺/傷人者：解除武器與危險品，警察搜身後再送醫。
- 行為異常，但無精神疾病者：可能因事件情緒起伏，未達自傷傷人程度。

#### 📘 約束與人權

可透過診斷測驗和功能測驗去評估個案的心理承受能力 (mental capacity)：

- 診斷測驗
  - 精神或腦部是否有損傷？
  - 損傷是否足以導致缺乏決策能力？
- 功能測驗
  - 瞭解相關資訊。
  - 保留並處理資訊。
  - 權衡利弊。
  - 能傳達決定。

#### 📘 社區精神病人護送就醫的相關法源依據

精神衛生法第48條賦予警察或消防人員在病人有傷害他人或自己之虞時，協助強制護送至醫療機構，並在必要時使用約束設備。

#### 📘 精神疾病案件的因應策略

- 注意自身與團隊成員安全。
- 詢問病人的主要問題。
- 評估病人的精神狀況。
- 留意病人是否有自殺意圖、計畫或攻擊行為。
- 以對病人最少的行動限制為原則。
- 詢問精神科藥物服用情況並隨車攜帶。
- 利用同理心傾聽與陪伴。

#### 📘 施救者的心理特質與救護技術員之應對技巧

救護員面對 DA-CPR 或 bystander CPR 的施救民眾，應給予正向回饋，切勿否定其行為。

### ⚡ 快速複習核心要點

- 出現痛苦、失能、社交困難、負面想法、自殺意圖時應尋求專業幫助。
- 社會安全網整合衛政、警政、社政等多方資源，以家庭為單位進行評估。
- 危機介入需辨識精神與行為急症，不要將所有案件都強制約束。
- 自殺風險評估須分辨自殺意念、企圖及自我傷害，勿使用刺激性字眼。
- DA-CPR案件中，給予施救民眾正向回饋與傾聽，可降低其創傷後壓力疾患。
