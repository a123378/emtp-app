# EMT-P 章節 Podcast 音訊檔存放處

此目錄供存放各章節專屬的錄音檔（例如從 **Google NotebookLM** 生成並匯出的 Deep Dive Podcast 雙人對談音訊檔）。

### 命名規則：
- `ch01.mp3`（第一章）
- `ch02.mp3`（第二章）
- ...
- `ch60.mp3`（第六十章）

### 運作機制：
網頁端 Podcast 播放器具備「雙軌相容」特性：
1. **優先載入**：若此目錄存在對應章節的 `chXX.mp3`，網頁端會直接播放該錄音檔。
2. **無縫備援**：若尚未放入 MP3 檔案，播放器將自動啟用內建的 **AI 智慧語音導讀電台**（Web Speech API），由系統自動將該章節的重點脈絡流暢朗讀，隨開即聽！
